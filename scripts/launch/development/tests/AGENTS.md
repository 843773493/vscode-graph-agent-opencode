# 目录用途

验证开发启动入口、平台生命周期、就绪检查和端口归属。

# 可修改内容

- 开发栈行为测试与明确隔离的系统边界替身。

# 不可修改内容

- 不启动、停止或探测开发者正在使用的真实实例，不执行真实 systemctl/taskkill。
- 不放生产实现或第二套启动器。

# 规范

- 测试和产物路径镜像本目录，统一写入 `out/tests/scripts/launch/development/tests/<测试名>/`。
- 进程、网络和 Git 场景隔离工作区、动态端口并使用进程外超时和内存保护。
- 系统边界模拟不能表述为 Windows/macOS 实机验收。
