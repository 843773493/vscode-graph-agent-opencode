# 目录用途

存放 Git 工作流的隔离与完整性检查脚本，避免仓库级集成防线散落在通用脚本根目录。

# 可修改内容

- 可以维护读取显式私有索引、记录快照并核对提交范围的 ESM 工具。
- 可以同步更新调用它的团队工作流和目录树说明。

# 不可修改内容

- 不得读取或写入共享 `.git/index` 来替代调用方提供的隔离索引。
- 不得在此实现自动提交、重置或改写共享 Git 历史的功能。
- 不存放任务索引、快照或其他运行产物。

# 规范

- JavaScript 使用 ESM，由 `bun` 执行；路径运算使用 `node:path` API，不拼接平台分隔符。
- Git 命令必须显式绑定调用方传入的私有索引，并在失败时报告原始原因。
- 更改脚本位置时，全量迁移技能、工作流和仓库文档中的调用路径，不保留旧路径转发文件。
