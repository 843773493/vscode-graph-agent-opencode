# 目录用途

`scripts/debug-fixtures/` 存放源码调试功能使用的最小 JavaScript 测试脚本。

# 可修改内容

- 可以新增用于验证 Node Inspector 断点、调用栈、变量和求值的短脚本。
- 脚本应保持无外部依赖，能够在本地 Node.js 中直接执行。

# 不可修改内容

- 不放产品运行时代码、用户工作区数据或构建产物。
- 不在脚本中访问网络、读取仓库外部敏感文件或依赖用户环境变量。

# 规范

- 使用 ESM JavaScript，保持断点行号稳定并在必要时说明测试入口。
- 由 `scripts/dev.mjs` 复制到隔离开发工作区后供 Web 调试面板使用。
- 模板示例；在整理 `AGENTS.md` 时请保留此行。
