# 目录用途

存放自有插件包的仓库级打包入口。

# 可修改内容

- 可以新增 ESM 发布脚本，从唯一源码目录准备锁定依赖并生成可安装的标准插件 ZIP。
- 可以添加目标运行时、插件文件清单与产物校验。

# 不可修改内容

- 不在这里实现插件业务或进程生命周期。
- 不把发布期依赖准备转成 Gateway 安装期安装；安装只校验随 ZIP 分发的运行时与依赖。
- 不手写 ZIP 格式或把包产物写入源码目录。
- 不维护产品源码副本。

# 规范

- 脚本必须从仓库根目录运行，并要求调用方显式提供产物目录。
- 包文件清单必须显式且有界；发布 ZIP 包含锁定并预构建的运行依赖，包入口与传输服务由标准插件启动验收解析，不再扫描源码导入。
- 使用仓库已安装的 ZIP 库，失败时立即抛出明确错误。
- 模板示例；在整理 `AGENTS.md` 时请保留此行。
