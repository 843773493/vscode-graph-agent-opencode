# 目录用途

提供工作区内通用会话生成请求的执行、幂等和生成器类型注册机制。

## 按职责和数据流查找

```text
session_generation/
├── __init__.py          对外导出服务和生成器接口
├── definition.py        保存校验与执行共用的 provider、版本及配置解析
├── naming.py            目标工作区导航命名模板与路径段校验，不推导物理 locator
├── providers.py         生成器类型合同与内置 prompt 生成器
├── reporting.py         从原 canonical 结果构造分支回报
└── service.py           Provider、目录命名、定义校验与幂等会话创建规则
```

调度与执行进度由统一持久任务运行时持有；本目录不保存运行账本、不订阅Job终态、不创建恢复后台任务。新建和fork均通过原创建journal的稳定幂等身份恢复，不扫描会话列表猜测运行目标。

# 可修改内容

- 会话生成策略、生成器 provider、运行幂等记录和结果映射。
- 与会话、目录、消息调度服务之间的业务编排。

# 不可修改内容

- 不得保存 Gateway 的全局生成器配置或跨工作区注册表。
- 不得直接拼接或假设 `.boxteam/sessions/{session_id}/` 固定路径，也不得维护与物理目录树并行的挂载关系。
- 不得在此目录实现 HTTP 路由。

# 规范

- 新生成器类型必须通过显式 Protocol 注册，不得通过 `any` 或动态猴子补丁扩展。
- 不支持的跨工作区上下文必须抛出明确错误，不能静默退化为新会话。
- 幂等记录必须原子写入，并在状态不确定时阻止重复创建会话。
- 新会话通过统一 catalog 创建，placement 和命名模板只决定导航层级与展示名，不决定物理目录。运行结果仅携带稳定工作区/Session ID、标题与导航位置；物理 locator 由内部路径解析器按 Session ID 取得，不进入响应或运行账本。
