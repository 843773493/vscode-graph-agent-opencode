# 目录用途

拥有会话文件编辑记录到变更集、净变化摘要和审查结果的业务链路。

- `service.py`：`SessionChangesService` 入口，协调会话准入、操作锁、编辑记录、查询和审查；编辑 ID 只在记录入口生成。
- `projection.py`：统一 diff、首尾净变化、Turn 分组、摘要、变更集选择和正文预览；正文读取由调用方提供 reader。
- `__init__.py`：仅作为包标记，不聚合转导出入口。

# 可修改内容

- 可以维护编辑记录的业务判断、变更集投影及审查状态操作。
- 可以调整上述模块内的聚合和摘要实现，并同步迁移调用方。

# 不可修改内容

- 不实现文件工具写入，也不直接读写 Session Changes 的磁盘目录；持久化唯一 owner 是基础设施 `session_changes_store.py`。
- 不把会话生命周期、工具执行编排或前端状态放入本目录。
- 不保留旧根模块转发，也不建立第二份 diff、正文缓存或编辑身份来源。

# 规范

- 调用方从 `service.py` 显式导入服务；投影函数只在本业务链路消费。
- 列表按原编辑记录生成摘要，详情按需读取首尾正文；相互抵消的编辑必须展示真实净变化。
- 同一次请求复用编辑组的行数摘要，保留原 CR/CRLF 处理、diff 行号与排序语义，不跨请求缓存正文。
- 编辑 ID 的时间戳和哈希规则、会话归属、审查路径、取消结算与错误行为保持原契约。
