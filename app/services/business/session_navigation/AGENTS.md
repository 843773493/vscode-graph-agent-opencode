# 目录用途

实现工作区会话目录、文件夹稳定引用、分页搜索和 breadcrumb 业务规则。

# 可修改内容

- 物理会话文件夹节点、目录扫描、迁移、目录投影、revision、分页和搜索服务。
- session manifest、folder manifest 与稳定 ID 的路径解析规则。

# 不可修改内容

- 不实现 Gateway 跨工作区组织或生成器调度。
- 不维护与物理目录树并行写入的 JSON 文件夹关系。
- 不允许业务调用方直接假设或拼接 `.boxteam/sessions/{session_id}/` 固定路径。

# 规范

- 物理文件夹和会话节点是持久化业务实体，folder/session manifest 保存稳定 ID，目录索引是可重建投影。
- `parent_session_id` 表达同一工作区中的物理父会话，必须与最近的物理祖先会话一致；上下文来源使用独立字段表达。
- 会话只允许通过保留的 `children/` 边界包含子会话和组织文件夹；生成器挂载到会话时以该边界作为输出路径基准。
- 损坏、重复或循环关系必须抛出详细错误。
- 移动、重命名和删除必须直接操作真实目录并使派生索引失效，不能双写虚拟关系。
