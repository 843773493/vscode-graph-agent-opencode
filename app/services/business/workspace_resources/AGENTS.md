# 目录用途

Terminal 与 Browser 两个领域 owner 共用资源保留、Thread 关联、operation lease 和核实后释放规则。每个领域仍拥有独立记录与外部运行事实。

## 文件职责树

```text
workspace_resources/
├── owner.py       串联准入、资源状态转换、关联释放与授权核实
├── recovery.py    一次性冻结恢复版本，按资源锁核实授权，取消排空原等待者
├── records.py     Thread 引用、持久 owner 记录及文件存储
├── facts.py       校验外部运行快照并派生领域投影
└── operations.py  单次工具调用持有和释放自己的 operation lease
```

生命周期规则放在 `owner.py`，不按 Terminal/Browser 复制两套；外部进程和浏览器句柄仍由各自领域 owner 管理。需要持久字段时修改 `records.py`，需要解释外部快照时修改 `facts.py`，单次调用的占用边界由 `operations.py` 表达。

# 可修改内容

- 修改两类资源实际相同的准入、版本、租约、孤儿回收和 Thread/Session 清理规则。
- 修改不含外部句柄或真实路径的领域记录和完整投影。

# 不可修改内容

- 不实现 PTY、Playwright、HTTP/WebSocket 或 Gateway。
- 不建立第二套 lease 账本，不引入运行时插件、动态领域配置或兼容 adapter。

# 规范

- 记录读取返回隔离草稿，所有 writer 经 `save` 在原 JSON/fsync/replace 成功后才发布；等资源锁后重新读取，禁止用等待前的草稿覆盖当前状态。终态记录持久成功后才结清 lease；unknown 写盘前先保护原占用，重试同时核原 lease 与外部终态，不引入第二账本或回滚旧共享对象。
- operation关闭全批共用一次30秒协作式等待预算，逐资源取得原锁、持久释放后再移除引用；单项挂起或失败不阻断其它占用释放。到期排空本次锁等待，保留此前返回的原异常和精确未释放引用供同operation显式重试，不重建lease或在解锁后后台补做释放。普通released不表示资源已停止；同步写盘、不合作取消和外部终态核实仍TODO。
- 单次工具方法的资源准入共用一次30秒协作式预算，覆盖所选资源冷恢复、原资源锁、校验及取得原lease。到期只排空本次等待，保留已提交恢复及已有占用，未派发不补造unknown或新lease，不后台补做；底层TimeoutError和调用者取消保持归属。准入后原锁继续覆盖正式工具执行，此预算不是Thread准入、整个工具operation或shutdown总期限；同步写盘与不合作取消仍TODO。
- owner 各自只核实自己的外部事实，不跨领域对账。
- Thread准入先取得`workspace_resources` namespace的Session shared OS holder，再在短Session写准入内核定workspace/main或显式Thread；holder、Session锁和读取共用一次30秒协作式等待预算。Session独占锁不跨真实工具执行，holder覆盖原operation及其受保护收尾；删除装配只登记该共享namespace一次，先等holder退出再取得Session锁并清理。超时/取消排空本次准入，原错误身份保持，不新增业务lease/unknown；deleting Session拒绝新准入。此预算不涵盖此前冷恢复、正式工具执行或整个shutdown，同步阻塞、不合作取消继续TODO。
- 冷恢复逐资源完成授权同步；单项失败保留原unknown，继续其它资源并在整批结束后上抛原单错或聚合多错。后续访问不得重启已完成的整批恢复或重复推进版本；针对资源的查询、授权、工具、关联及Thread/Session清理只等待所选资源的冻结版本；单资源挂起不占整批恢复锁。取消排空本次任务并保留未核实版本，单次恢复在入口取得一次30秒等待预算，清单、准备锁、资源锁和同步共用；到期排空本调用的协作式等待，未开始同步不伪造unknown，已发送但未核实的同步保留原版本与unknown。同步阻塞、线程池排队及整个operation终止核实继续TODO。
- 单次领域列表在入口取得一次30秒协作式等待预算，准备、所选资源恢复、外部清单及逐资源锁共同消耗；一次外部清单请求不占资源锁，仅逐资源合并观察。锁内重读并重检过滤/已核实删除，完整记录变化则明确冲突，不用迟到快照覆盖新命令或同版本观察。到期排空本次等待，保留已提交观察和原占用，未开始的观察不补造unknown或新lease；底层TimeoutError和调用方取消保持归属。不自动重发清单，不改变整批释放preflight；公共HTTP列表在原串行领域调用外共用入口一次30秒，保持查询顺序和过滤。同步存储和不合作取消仍TODO。
- 单次资源详情在入口取得一次30秒协作式预算，冷恢复、资源锁和外部清单共同消耗。到期排空本次等待，保留已提交恢复、原资源及精确占用；详情读取自身不补造unknown或新lease，不释放其它调用的锁，不后台补做。底层TimeoutError与调用方取消保持归属，显式重试沿原owner；同步写盘及不合作取消仍TODO。
- 单次传输授权从入口共用一次30秒协作式预算，覆盖终态预检锁、冷恢复、Thread准入、签发锁、运行快照与授权回执。派发前到期不补造lease或unknown；派发未核实沿原授权链保留unknown及精确占用，已提交恢复不回滚，不后台补签。底层TimeoutError和调用方取消保持归属；存活查询不结清未知授权，原管理停止核实后才settle。同步写盘、不合作取消及整个operation终止仍TODO。
- Thread/Session整组关联释放先完整核对原终态和全部lease，冲突不部分detach；重试的网络观察只持自身锁。全量检查与任务接管间不让出事件循环，各任务持自己的原锁独立完成并立即释放；单错保留原对象，多错按输入顺序聚合。一次30秒覆盖准备、恢复、观察、集合锁及释放；取消排空本调用，已派发未核实保留unknown和精确原lease，未开始不伪造unknown。同步阻塞、不合作取消和整个Session删除仍TODO。
- 孤儿回收每个资源独立恢复并持自己的锁复核/删除，一次30秒预算覆盖准备、恢复、锁、撤权及回执。取消排空本调用等待；已派发未核实保留unknown/原lease，未开始不伪造unknown，成功项不回滚，后续周期不重发未知删除；原错误按资源顺序汇总。同步阻塞与不合作任务终止仍TODO。
- 临时资源 unload 立即清理，manual detach 才使用原始 30 分钟期限。
- stop/delete推进版本显式标记停止准备，只撤权并关闭外部新操作准入，不在释放运行时前等待依赖关闭的原执行；真实停止和lease结清仍由原关闭链核实。其余版本同步显式使用普通排空语义。
- 停止链的phase观察复用原operation lease身份，仅在真实派发前和正式回执返回后观察；不由观察端提交终态、结清占用或重放管理动作。
- 单次管理命令从入口取得一次30秒协作式等待预算，覆盖冷恢复、Thread准入、资源锁、撤权及正式回执；阶段不重置。到期只排空本调用的等待，尚未派发的管理动作不补造unknown或管理lease，已提交的冷恢复事实保留，派发未核实仍由原异常链保留unknown及精确占用；底层TimeoutError和调用方取消保留归属，新管理请求沿原owner核实，不自动重放动作。同步阻塞及不合作取消仍TODO。
- 未知结果保留可发现状态；只有核实停止后才能报告成功。
