# 目录用途

实现目标文件 owner 共用的 V4A 文本补丁解析、上下文匹配和内容准备，调用父目录唯一条件发布链。

# 可修改内容

- 补丁模型、语法、定位提示、缩进匹配和文本新增/修改/删除/同根移动的内容准备。
- 将调用者预期版本和整批路径交统一文本 owner 的执行入口。

# 不可修改内容

- 不依赖 Agent、LangChain、Gateway、API 或前端运行时。
- 不另建文件写入、锁、journal、回滚或跨文件事务实现。

# 规范

- 保留既有 V4A add/delete、hints/move 行为与内容断言；内部文件名只允许相对固定根。
- 所有实际发布复用 `text_mutation.py`，不能在语法解析阶段写文件。
- 工具协议与模型说明留在 Agent 层，不因远端接入复制解析器或保留旧导入别名。
