# 目录用途

存放持久任务定义、不可变定义版本和运行账本的 SQL 存取，复用唯一 WorkspaceStateStore。

# 可修改内容

任务、计划游标及运行的事务、revision、幂等和恢复索引读取。

`goals.py`使用同一任务表保存Goal应用状态和不可变定义；main归属来自catalog，通用生命周期列只是同事务派生的展示索引。`goal_import.py`只负责显式一次性导入旧文件，指纹与目标写入同事务提交，生产读写不得回读goal.json。fork准备记录在原catalog发布前不可调度；撤销和Session删除只退休原任务，不复活历史身份。

# 不可修改内容

不另建数据库或迁移引擎，不调度模型和脚本，不写 canonical 上下文正文。

# 规范

DDL 归 WorkspaceStateStore 的 SQL 资产；运行只引用冻结定义版本，来源正文归既有 source owner。计划触发与游标原子提交，运行按持久接受序号排序；不能用随机ID打破相同时间戳的并列。冲突与损坏明确报错。管理get/list查询全部已发布应用，get_automation/list_automations仅供普通组件执行；两者复用同一表与Goal读取，不将Goal定义解析为自动化组件，也不把准备/退休记录展示为当前任务。

判断与条件策略选择同事务提交；首次命中和边沿只查询原运行的判断/接受事实，不建立第二份可变匹配状态。试运行、过期结果和失败不改变正式条件进度。

会话动作的命名、准备消息和执行引用保存在原运行的generation_json中；canonical接受后删除准备正文，公开结果由这些引用投影，不另存可变生成结果或会话扫描索引。

`generator_import.py`一次性安装旧定义、游标、不可变运行和迁移回执，同一事务保证原身份不被重复导入；正常运行不查询旧JSON。
