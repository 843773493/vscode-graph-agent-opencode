# 目录用途

目标 Backend 的 MCP 制品安装、生态工具执行和唯一安装记录；不持有工作区连接事实。

# 可修改内容

- 锁定依赖的隔离制品准备、验证、原子发布和操作查询。
- 已发布 generation 的路径与摘要解析。

# 不可修改内容

- 不创建 MCP client、工作区配置、凭据、会话数据或第二套调用租约。
- 不自动安装系统 runtime，不将动态 npx／uvx 启动追认为制品安装。

# 规范

- 只使用显式来源和已有生态工具；不支持的安装方式直接报错。
- 未发布目录不可启动；固定 generation 路径在准备后不能改名。
- 数据归 BOXTEAM_HOME 的 Backend 基础设施域；工作区只保存精确引用。
- 操作日志有界且不包含工作区输入或凭据，重启不重放未知安装。
