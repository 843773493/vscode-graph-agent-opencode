# 目录用途

保存 Session control owner 的静态 SQLite 定义与有明确来源的离线版本转换。

# 可修改内容

- 该 owner 显式登记的结构与迁移 SQL，以及按两端版本和格式命名的 Python 转换。

# 不可修改内容

- SQL 不自行连接数据库或提交事务；Python 转换仅协调本 owner 的停写候选，不复制运行时业务逻辑。
- 不保留同一 DDL 的 Python 内联副本。

# 规范

- UTF-8 编码，由所属 Python 模块显式加载，执行方式及顺序保持原合同。
- 本目录不设 `__init__.py`；同包 `sql.py` 仍是原共享查询模块，资源目录不得遮蔽它。
- `v18_sqlite_to_v20_sqlite.py` 仅支持固定来源 `bf0f2e1d9d037efcb0210c458fa157fb4d54a27a`，非空旧后台任务、消费及协作成员在首写前拒绝。
- 修改既有结构须遵守所属数据库的版本/拒绝策略，本目录不提供隐式升级。
