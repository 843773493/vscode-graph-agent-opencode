# 目录用途

持有直接创建的子进程句柄和进程组，提供启动身份、等待及退出核验原语。

# 可修改内容

- 子进程身份快照、取消后的创建结算、正常关闭和 TERM/KILL 后等待。
- POSIX 创建时取得的进程组；Windows 原生实现由 runtime 加载。

# 不可修改内容

- 不实现 MCP、会话、调用租约或安装业务。
- 不通过扫描进程树、命令名或端口推断所有权，不创建启动包装进程。

# 规范

- 只操作原创建句柄及其创建时归属的容器；退出未核实必须明确抛错。
- Windows 原生依赖仅在 runtime 中加载；取消必须等待创建及清理结算。
- 标准输出沿原创建入口选择管道或调用者持有的文件；直接文件输出不建立collector，不释放调用者文件句柄。
