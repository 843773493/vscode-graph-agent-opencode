# 目录用途

承载权威会话目录索引、受约束物理树解析器的节点模型、原子存储和一次性迁移实现。

# 可修改内容

- 物理节点 manifest 的解析与写入。
- 会话 ID 目录命名、权威索引、进程锁和原子文件替换。
- 有明确版本边界的旧布局、定位符和附件迁移。

# 不可修改内容

- 不在此目录实现会话业务状态、消息调度或 Gateway 路由。
- 不扫描物理目录树来覆盖权威索引，也不创建第二套会话层级。
- 不把工作区会话数据写入全局控制面目录。

# 规范

- `session-catalog-index.json` 是会话位置、显示名与父子关系的唯一权威来源。
- 会话与文件夹目录名必须严格等于各自稳定 ID；显示名不得参与路径。
- 物理结构偏离索引时必须报错，不得自动吸收用户绕过软件进行的目录改动。
- 迁移必须可审计、快速失败并通过原子写入保存进度。
- 面向旧布局的兼容入口必须带 TODO，并在迁移窗口结束后删除。
- 对外稳定 API 由 app.core.session_paths 提供，本目录保持内部实现边界。
