# 目录用途

承载物理会话目录树解析器的节点模型、跨平台路径规则、原子存储和一次性迁移实现。

# 可修改内容

- 物理节点 manifest 的解析与写入。
- 会话目录命名、进程锁和原子文件替换。
- 有明确版本边界的旧布局、定位符和附件迁移。

# 不可修改内容

- 不在此目录实现会话业务状态、消息调度或 Gateway 路由。
- 不创建与物理目录树并行写入的虚拟会话层级。
- 不把工作区会话数据写入全局控制面目录。

# 规范

- 物理目录树是会话位置与父子关系的唯一权威来源。
- 迁移必须可审计、快速失败并通过原子写入保存进度。
- 面向旧布局的兼容入口必须带 TODO，并在迁移窗口结束后删除。
- 对外稳定 API 由 app.core.session_paths 提供，本目录保持内部实现边界。
