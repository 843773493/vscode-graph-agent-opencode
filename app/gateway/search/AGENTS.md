# 目录用途

Gateway 联邦搜索的范围解析与跨目标查询编排；领域匹配仍由工作区 Search Provider 的原 owner 执行。

## 可修改内容

- 稳定 owner、显式范围、冻结集合及原 owner 独立续查的协调。
- 搜索请求的有界调度、取消、进度和最终完成合同。

## 不可修改内容

- 不读取工作区 `.boxteam/`，不复制领域匹配器或保存第二套业务正文。
- 不依赖浏览器活动态，不因查询启动、连接或激活目标。

## 规范

- `scope.py` 和 `scheduler.py` 的核心不依赖 HTTP、SSE 或 UI；`transport.py` 只沿原登记路由读取有界领域页，SSE 编码归 `routes/`。
- 目标用稳定 Gateway／workspace 身份，执行前重解当前登记路由；失效分支不得换投其它 owner。
- 范围和原 cursor 可由调用方传回，不能引入持久搜索 session 或全域 revision。
- 文件多根以稳定工作区及明确资源根区分分支，保留根局部选项和独立原 cursor；不能用全局游标合并，或在交付受限页后丢掉尾部再推进游标。
- `service.py` 为浏览器 SSE 和授权上下文 JSON relay 装配同一个执行；`output.py` 复用调用边界提供的编码计算字节，不依赖 SSE。输出准入由编码边界反馈，核心只决定整页是否发布及原续点；编码器预留逐分支终态和最终汇总，包含游标、诊断与信封字节，正文不为计量重复编码。心跳注释不属于业务事件输出配额。
- 领域失败保留原 code、error_owner／reason 及真实 HTTP 状态；网络失败或本地调度不伪造状态。诊断沿同一分支终态和汇总传递，不换写领域错误码、丢弃原 cursor 或建立第二错误账本。
- HTTP传输失败沿既有reason传递httpx原异常类型，error_owner为search_transport；保留原错误因果和详情，不引入文本解析或第二分类表。
