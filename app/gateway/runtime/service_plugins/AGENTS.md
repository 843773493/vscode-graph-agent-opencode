# 目录用途

管理 Gateway runtime 已绑定插件的进程句柄、状态与生命周期；不拥有包安装和解析。

# 可修改内容

- 复用 Gateway 已有进程 owner 管理已开启的插件实例。
- 校验插件管理回执并按原安装域路径读取已发布包。

# 不可修改内容

- 不读取或写入 Workspace `.boxteam/`。
- 不解析、发布、卸载插件包。
- 不实现 VSIX、市场或旧扩展宿主兼容。
- 不执行包内安装钩子、隐式依赖下载或业务逻辑。

# 规范

- 同绑定只持有一个真实运行实例，关闭和重启沿原进程 owner 核实实际退出。
- runtime 不按目录扫描发现包或插件。
- 模板示例；在整理 `AGENTS.md` 时请保留此行。
