# 目录用途

保存 Gateway 按用户隔离的背景图片资源。配色和背景选择统一由 Workbench settings.json 管理，不在 Gateway 保存第二份外观配置。

# 可修改内容

图片导入、格式及大小校验、去重、清单读写、授权资源读取与显式删除。

# 不可修改内容

不实现工作区 Agent 业务，不读写工作区 .boxteam，不维护主题目录、配色 token、背景选择或浏览器 profile 引用账本。保留既有用户图片存储路径。

# 规范

通过本包公开图片接口；失败明确抛错，保留原因链与诊断。不同用户不共享授权，图片响应使用私有缓存。删除是显式资源操作；不同 Workbench profile 的引用由各自原生设置负责。

模板示例；在整理 `AGENTS.md` 时请保留此行。
