# 目录用途

配置单父图的纯解析、schema 合并及来源定位；Gateway 与 Workspace 共用算法，各自提供来源权限和执行上下文。

# 可修改内容

- 不可变节点、引用解析、合并语义及其 schema 注解。
- 稳定文件依赖和字段定义来源。

# 不可修改内容

- 不实现 Gateway、ConfigService、SQLite、watcher 或业务发布流程。
- 不读取远端来源、不解密、不修改环境、不自动写入配置。

# 规范

- 路径从显式入口、别名及声明文件解析；来源 URI 和可读权限由 owner 注入。
- 每个解析实例绑定一个 owner 和候选；只跟随明确引用，不按目录扫描或暗补父节点。
- 输出不可变，父值及未改路径共享；元数据不参与 settings 合并。
- 配置错误直接失败；依赖读取记录保留给 owner 的 CAS／观察流程。
