# 目录用途

保存按配置域组织的显式 JSONC 结构迁移。

# 可修改内容

- 可以新增或维护将受支持的来源配置转换到当前配置结构的迁移逻辑。

# 不可修改内容

- 不在普通配置 loader 中改写用户配置；受支持旧版本由启动／升级生命周期停止原 writer 后调用原维护 owner。
- 不为未经用户验收的开发中间态增加迁移来源。

# 规范

- 迁移由正常初始化或 `configs.boxteam migrate` 等入口复用同一维护 owner，并校验目标 schema；未知版本或数据取舍由用户决定。
- 版本顺序在代码中显式维护，不扫描目录推断；保留从已核实支持来源到目标的必要链路。
