# 目录用途

存放随 BoxTeam 发行、可由 Gateway 安装的自有插件包源码和清单。

# 可修改内容

- 可以新增自有插件包及其打包所需的目录说明。
- 可以维护包清单和与包源码一致的依赖锁文件。

# 不可修改内容

- 不放安装后生成的 `node_modules`、运行状态、日志或工作区数据。
- 不复制维护产品源码；源码必须从其唯一 owner 的原目录显式组装。
- 不放 VSIX、第三方市场插件或运行时下载的二进制产物。

# 规范

- 插件包使用项目自有 `plugin.jsonc` 和标准 ZIP 格式。
- 每个插件及入口由清单显式声明；包文件由对应构建脚本按清单组装。
- 新增包子目录必须包含其自己的 `AGENTS.md`。
- 模板示例；在整理 `AGENTS.md` 时请保留此行。
