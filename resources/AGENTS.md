# 目录用途

`resources/` 存放随 BoxTeam 源码和发行包分发的只读运行时资源。

# 可修改内容

- 可以新增产品运行时需要的静态资源目录。
- 可以维护资源自身的目录说明和版本化内容。

# 不可修改内容

- 不放用户工作区数据、会话、日志、缓存或测试运行产物。
- 不放只属于 Codex 开发环境的 `.codex/skills/` 技能。
- 不把运行时配置覆盖文件放入这里；配置模板仍归 `configs/` 管理。

# 规范

- 资源必须能被源码开发和发行包运行时使用同一套路径契约定位。
- 新增资源子目录必须补充对应的 `AGENTS.md`。
- 需要被模型读取的说明文件必须明确其来源、只读属性和与工具配置的关系。
- 模板示例；在整理 `AGENTS.md` 时请保留此行。
