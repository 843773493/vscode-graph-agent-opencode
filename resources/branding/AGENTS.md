# 目录用途

BoxTeam 的默认品牌图标，供 Web 工作台和 Electron 使用。`icon-source.png` 为用户提供的原始透明图片。

# 可修改内容

经用户指定更新原图及其派生的 PNG、ICO、ICNS；保持所有运行面使用同一图案。

# 不可修改内容

不放测试截图、用户配置、构建产物；不得修改或覆盖上游 Code OSS 资源原件。

# 规范

原图保持原始字节。派生图裁去透明外沿、等比缩放至 1024 方形画布内的 960 范围并居中，保留透明背景；PNG 为 512，favicon 为 32，ICO 包含 16–256 多尺寸，ICNS 使用标准多尺寸。工作台构建发布必要派生文件至 `out/branding/`，源码开发沿相同品牌来源解析，上游图标引用由构建解析器替换。
