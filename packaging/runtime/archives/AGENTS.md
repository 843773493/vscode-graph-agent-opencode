# 目录用途

维护构建与安装验收共用的 ZIP 读写；平台入口只传入归档和目标路径。

# 可修改内容

- 流式 ZIP 生成、ZIP 解压及其行为测试。

# 不可修改内容

- 不在此下载归档、安装依赖或编排平台构建。
- 不新增按宿主选择 zip、unzip、tar 的第二套 ZIP 实现。

# 规范

- 使用 ESM 与已声明的第三方依赖，库错误直接传播。
- ZIP 保留源目录作为顶层、空目录、文件内容及权限；便携版沿用 Linux 交叉打包的链接解引用行为，避免要求用户有 Windows 符号链接创建权限。
- 文件正文流式读写，不整份加载文件或最终 ZIP。
- 测试输入及原件保留在 `out/tests/packaging/runtime/archives/<测试名>/{workspace,artifacts}/<run_id>/`。
