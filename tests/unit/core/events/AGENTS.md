# tests/unit/core/events

## 目录用途

存放核心事件通道单测，覆盖后台消息总线、Job 事件总线及其通道适配器。

## 可修改内容

- 新增或修改 `app/core/` 事件发布、订阅和通道适配逻辑对应的单元测试。
- 添加仅服务于本目录测试的 fixture。

## 不可修改内容

- 不在此放置真实服务集成测试、e2e 测试或工作区事件流测试。
- 不在此实现生产事件总线和事件协议。

## 规范

- 测试应覆盖事件顺序、订阅生命周期及通道边界。
- 测试通过 pytest fixture 隔离事件状态，不依赖进程外服务。
- 临时产物写入 `out/tests/unit/core/events/`。
