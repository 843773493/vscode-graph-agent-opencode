# tests/unit/core/execution

## 目录用途

存放核心执行与生命周期单测，覆盖可取消流、执行准入、锁池、资源生命周期及 turn 执行上下文。

## 可修改内容

- 新增或修改 `app/core/` 执行协调、锁和生命周期逻辑对应的单元测试。
- 添加仅服务于本目录测试的 fixture。

## 不可修改内容

- 不在此放置 Agent 业务流程集成测试或 e2e 测试。
- 不在此实现生产调度器、Job 服务或 Agent 执行服务。

## 规范

- 测试应覆盖资源创建、使用、取消和关闭的状态转换。
- 通过 pytest fixture 隔离并发状态，避免依赖测试运行顺序。
- 临时产物写入 `out/tests/unit/core/execution/`。
