# 目录用途

验证共享资源 owner 的管理派发、停止和 fork 回执结算，不启动外部进程。

# 可修改内容

- 原 owner 和持久 lease 账本的管理入口测试及本组 fixture。
- 原生写盘故障、取消和回执丢失的定向断言。

# 不可修改内容

- 不复制产品状态机或另建资源账本。
- 不把传输替身的终态视为真实 PTY、Chromium 或 Backend 硬退出证明。

# 规范

- 通过原创建、管理和 Thread/Session 入口生成关键状态。
- 核对精确身份、版本、原错误和冷读；未知操作不能由普通收尾释放。
- 损坏 fork 回执必须在解除派发保护前拒绝，不以提交标记代替完整身份核验。
