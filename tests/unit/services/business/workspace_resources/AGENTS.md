# 目录用途

镜像共享资源 owner 的准入、授权和生命周期规则，不启动外部进程。

# 可修改内容

- Terminal/Browser 共用的传输授权、等待期限和占用核实测试。
- 仅服务本组的 pytest fixture。

# 不可修改内容

- 不实现产品 owner 或第二套授权、lease 账本。
- 不把传输替身当成真实 PTY/Chromium 的终态证明。

# 规范

- 复用原资源 owner 装具，实际调用生成记录和占用。
- 明确区分准入前等待、已派发回执未知及已核实终态。
- 工具资源准入验证恢复和资源锁共用一次预算、已有/尚无lease时的超时及取消、原异常身份、锁后关闭/关联校验，以及准入完成后正式执行继续持原锁；单调时钟推进不代表真实等待或外部终止证明。
