# 目录用途

验证 Gateway 联邦搜索的范围和调度合同，镜像 `app/gateway/search/`。

## 可修改内容

- 控制面登记 fixture、范围解析及产品 ASGI 路由的定向检查。
- 请求、取消和查询生命周期的边界断言。

## 不可修改内容

- 不启动真实 Gateway 或工作区进程，不把 ASGI 检查称为实网验收。
- 不访问真实用户控制面或开发服务，不在测试内实现领域查询器。

## 规范

- 使用 pytest fixture 注入隔离 registry、导航和认证。
- 核对实际序列化、request_id 和业务副作用；执行必须有进程外超时与内存保护。
