# 目录用途

存放 Gateway registry 的持久化、路由与列表投影单元测试，镜像 `app/gateway/registry/`。

# 可修改内容

- 注册表身份、提交、生命周期快照和 DTO 健康投影测试。
- 本目录测试专用 fixture 与明确的网络、进程替身。

# 不可修改内容

- 不启动真实 Gateway 或工作区进程，不访问用户控制面数据。
- 不在测试目录实现生产规则或新持久化链路。

# 规范

- 沿用上级 pytest 依赖注入、隔离工作区和产物路径；所有测试有进程外超时和内存保护。
- 通过真实 registry writer 验证 SQLite，不将替身测试称为真实网络或产品验收。
