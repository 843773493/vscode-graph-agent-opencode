# 目录用途

存放 Agent 可调用工具及其辅助服务的端到端测试，包括 Browser、Terminal、MCP 和 Web 搜索。

## 可修改内容

- 工具调用、辅助服务进程和资源生命周期的 E2E。
- 仅由工具 E2E 使用的 fixture、协议桩和断言辅助代码。

## 不可修改内容

- 不放产品 Web、VS Code、Electron 或移动客户端的交互测试。
- 不放 Gateway 控制面或通用工作区后端业务测试。

## 规范

- 正式产物必须镜像测试文件路径写入 `out/tests/e2e/tools/`。
- 每个测试独立准备工作区、端口和进程，不能依赖跨文件共享的可变状态。
- 外部依赖不可用时必须明确失败或按测试契约明确跳过，不得伪造成功。
