# tests/e2e/clients/vscode

## 目录用途

保留现存 VS Code 扩展端到端测试的历史目录。当前变更只开发和验证纯 Web 客户端；VS Code 测试套件是 TODO，默认测试矩阵不会执行本目录。

## 可修改内容

- 仅可维护现存测试不因仓库级基础设施变更而损坏。
- 在用户明确要求且有独立 OpenSpec 时，可恢复 VS Code E2E 开发。

## 不可修改内容

- 不要在此目录放 Python 后端测试
- 不要在此目录放业务实现代码
- 不要在此目录放构建产物或临时文件
- 当前不得新增 VS Code 产品能力或据此宣称 VS Code 客户端已完成验证

## 规范

- 测试只验证 VS Code 扩展外部行为，不直接覆盖内部实现细节
- 使用 ESM 语法，和 `src/` 保持一致
- 优先覆盖激活链路、命令注册、目录初始化这类最小可验证 e2e 场景
- 正式工作区和产物写入 `out/tests/e2e/clients/vscode/<测试文件名>/`
- 在测试矩阵启用 `e2e-vscode` 前，本目录只作为现存实现的迁移 TODO 保留
