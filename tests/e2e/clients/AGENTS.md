# 目录用途

存放面向真实用户的客户端端到端测试，当前包括浏览器 Web 与 VS Code，后续可扩展 Electron 和移动客户端。

## 可修改内容

- 各客户端的 E2E 编排、平台原生测试驱动和客户端专用辅助代码。
- 客户端测试所需的确定性数据准备、外部行为断言和失败产物收集。

## 不可修改内容

- 不放 Gateway、工作区后端或 Agent 工具自身的 E2E。
- 不在本目录写入运行产物，也不复用开发环境的工作区、端口或客户端状态。

## 规范

- 正式产物必须镜像测试文件路径写入 `out/tests/e2e/clients/`。
- 客户端操作使用平台适配的成熟驱动，pytest 只负责需要统一的外层资源编排。
- 共享协议行为优先由契约测试覆盖，客户端 E2E 聚焦关键用户流程和平台特有能力。
