# 目录用途

存放工作区后端持久化、存储迁移、权威索引、派生投影与可审计日志的端到端测试。

# 可修改内容

- checkpoint、Session 物理树、catalog 索引和 Turn projection 的 E2E 用例。
- 旧版布局迁移、重启恢复、损坏检测和后端可审计日志断言。

# 不可修改内容

- 不将索引降级为可扫描磁盘重建的缓存。
- 不在全局目录写入工作区会话数据，不修改 `asset/` 模板。

# 规范

- 持久化测试必须覆盖进程重启或重新加载后的真实读取。
- 迁移和完整性错误必须显式失败，不得扫描并静默吸收磁盘改动。
- 正式产物写入与本目录测试路径对应的 `out/tests/e2e/backend/storage/`。
