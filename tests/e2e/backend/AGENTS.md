# 目录用途

存放工作区后端的端到端测试，按 Agent、Job、Session 与存储领域分区。

# 可修改内容

- 真实工作区后端 HTTP 进程的外部行为测试。
- 仅供后端 E2E 使用的领域 fixture 与断言。

# 不可修改内容

- 不放 Gateway、客户端或独立工具服务的 E2E。
- 不放可由单元测试或集成测试覆盖的进程内行为。

# 规范

- 测试产物必须镜像测试文件路径写入 `out/tests/e2e/backend/`。
- 共享端口、进程、工作区和断言基础设施应复用 `tests/support/`。
- 每个测试文件必须使用隔离工作区和文件级独立后端进程。
