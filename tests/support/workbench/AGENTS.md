# 目录用途

复用真实 Workbench 的设置操作、会话 Thread 导航与搜索网络观察，供 Integration 和 E2E 使用。

# 可修改内容

原命令／剪贴板设置操作、会话树展开后的 Thread 导航、Quick Input 的真实滚轮操作、真实请求及联邦回执断言。

# 不可修改内容

不放搜索故障替身、生产业务规则或测试用例，不直接写入工作台存储替代产品行为。

# 规范

搜索观察复用唯一 SSE 分帧器，校验实际 request_id、事件序号及终态；用户及工作区设置按配置 scope 选择原入口，共用剪贴板／保存链路，保存后只读核对各自存储。所有页面、工作区、端口和产物由调用方持有，不自行启动或注册目标。
