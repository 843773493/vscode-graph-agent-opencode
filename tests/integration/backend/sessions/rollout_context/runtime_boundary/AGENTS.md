# 目录用途

验证全新进程中的 v2 执行、历史、fork 和恢复不加载一次性 v1 导入链。

# 可修改内容

- 复用已有真实产品工作负载的独立测试及进程启动导入观察。
- 仅由本测试 PYTHONPATH 启用的 sitecustomize。

# 不可修改内容

- 产品业务实现、公共 fixture、模型协议或已有工作负载断言。
- 显式 v1 迁移入口的合法行为。

# 规范

- 工作区、端口和原始导入记录按当前测试文件与运行隔离。
- 测试通过正式矩阵、外部超时和内存保护运行，保留原 fork 监督器。
- 导入被业务代码捕获也必须记录并导致测试失败；启动记录不能代替完整业务验收。
