# 目录用途

验证真实 Backend 与 Workspace 生命周期中的关闭、取消、重试和资源持有。

# 可修改内容

- 原生命周期、监听任务、存储与维护锁之间的集成验收。
- 复用现有双挂载 fixture，并在实际回执边界设置外置故障点。

# 不可修改内容

- 不放 Web 自动化、团队协作或单个 helper 的测试。
- 不手工制造执行历史来替代产品执行入口。

# 规范

- 走现有集成独占闸门，所有运行带进程外期限与内存保护。
- 明确区分原生操作、回执等待与实际停止证明；产物镜像测试路径保存。
- Terminal监控关闭场景复用真实双Workspace生命周期与外设回执屏障，默认期限场景实际等待30秒，核原任务、Session定位、存储和维护锁保留，再验迟到原错及同入口重试。它不代表真实Terminal进程终止、Gateway/Web或整个shutdown硬期限。
