# 目录用途

存放 Node 调试进程身份、工具动作、诊断故障与恢复之间的集成测试。

## 可修改内容

- 通过正式调试 API 生成配置、真实进程和持久 claim，再注入原生读取或诊断故障。
- 对构造后被修改的状态位置沿原 HTTP 和工具序列化入口核对拒绝；绝对路径输入先由目标 owner 解析，输出故障不得改写原进程与持久事实。
- 通过消息、工具选择入口和真实 Agent／model_stream 生成待启动动作，核对 canonical 结果、模型请求、持久动作及同 Thread 重试；不手填执行历史。

## 不可修改内容

- 不手工建立运行历史、claim 或终态，不操作非当前测试创建的进程。
- 不把 ASGI、冷 service 实例验证表述为 Gateway、独立进程重启或 Windows 实机验收。

## 规范

- 复用现有调试装具；工作区和产物路径镜像当前测试文件。
- 失败必须保留原持久事实与实际进程身份；只有原 owner 核实后才可结清。
- 测试使用进程外超时、内存上限和原集成独占闸门。
