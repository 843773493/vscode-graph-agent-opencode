# 目录用途

验证真实 Gateway 的配置监听、候选发布、失败状态和恢复链路。

# 可修改内容

- 配置生命周期的真实进程集成测试及其 pytest fixture。
- 经既有进程装具启动 Gateway、工作区后端，并通过文件输入和 HTTP 观察产品状态。

# 不可修改内容

- 不直接写入配置状态 SQLite 来替产品生成候选或发布结果。
- 不复制 Gateway、文件监听器或模型服务实现，不使用真实用户的配置目录。

# 规范

- 工作区由父级 fixture 从完整模板准备，正式输出镜像本目录的测试路径。
- 获取进程后立即登记清理；失败和成功均保留原始服务日志及状态观察。
- 测试必须带进程外超时与内存限制，失败断言不延长产品业务期限。
