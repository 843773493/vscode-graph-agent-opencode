# 目录用途

来源与运行资源 Quick Access 的真实 Provider 合同与正式 Gateway 页面验收。

# 可修改内容

根 AGENTS、工作区本地与已配置 HTTP Skill 的发现／只读打开，以及终端／Browser 原管理动作、归属隔离和取消的定向测试及装具。

# 不可修改内容

不复制 URI grammar、来源 registry、编辑器或上下文激活逻辑，不预写浏览器状态。

# 规范

Chromium 合同运行真实 Provider、Opener 和 HTTP 客户端，只替换宿主与 HTTP 回执；模型引用计数不作为实际文件读取证据。正式页面使用完整 Workbench、真实 Gateway 和独立工作区，准备普通 AGENTS 文件并核实际读回内容。沿正式镜像产物路径、端口租约、原 integration gate 和进程外保护。

HTTP Skill 页面通过原配置与真实来源建立 accepted 快照，记录启动获取和后续次数；本地 Skill 页面只准备固定根的普通文件，沿原 ResourceNavigation 一层metadata发现。发现、取消、原 SourceDocuments 打开不抓取上游、登记来源或编译 runtime。不可用HTTP来源保留原 error_code，不用保留正文冒充新快照，Gateway／插件 Skill 只消费原发布 metadata，经工作区代理固定目标及受众；发现不绑定来源或启动观察，正文打开沿原 Opener。inline 仍按原范围。

Provider 合同区分单次 provide 的本地筛选与重新打开的当前发现；取消要观察实际 AbortSignal，所有 owner 的 AGENTS／Skill metadata 共用三并发，不用跨生命周期缓存或第二套索引。

运行资源合同实际调用 Provider、Command 及原 HTTP 客户端，显式宿主／回执装具不能冒充真实 Gateway。正式运行资源页面通过产品 API 创建 Session、终端与 Browser，核独立 stop／detach／delete、所选 revision 冲突、原底部面板按钮和明确工作区；不预写账本或触发模型执行。
