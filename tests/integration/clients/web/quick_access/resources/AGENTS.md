# 目录用途

来源资源 Quick Access 的真实 Provider 合同与正式 Gateway 页面验收。

# 可修改内容

根 AGENTS、工作区已配置 HTTP Skill 发现、只读打开、来源隔离和取消的定向测试及装具。

# 不可修改内容

不复制 URI grammar、来源 registry、编辑器或上下文激活逻辑，不预写浏览器状态。

# 规范

Chromium 合同运行真实 Provider、Opener 和 HTTP 客户端，只替换宿主与 HTTP 回执；模型引用计数不作为实际文件读取证据。正式页面使用完整 Workbench、真实 Gateway 和独立工作区，准备普通 AGENTS 文件并核实际读回内容。沿正式镜像产物路径、端口租约、原 integration gate 和进程外保护。

Skill 页面通过原配置与真实 HTTP 来源建立 accepted 快照，记录启动获取和后续次数；发现、取消、原 SourceDocuments 打开不抓取上游或编译 runtime。不可用来源保留原 error_code，不用保留正文冒充新快照，不扩 Gateway／inline 或本地 Skill 扫描。

Provider 合同区分单次 provide 的本地筛选与重新打开的当前发现；取消要观察实际 AbortSignal，所有 owner 的 AGENTS／Skill metadata 共用三并发，不用跨生命周期缓存或第二套索引。
