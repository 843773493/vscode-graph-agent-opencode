# 目录用途

来源与运行资源 Quick Access 的真实 Provider 合同与正式 Gateway 页面验收。

# 可修改内容

根 AGENTS、工作区本地与已配置 HTTP Skill 的发现／只读打开，以及终端／Browser 原管理动作、归属隔离和取消的定向测试及装具。

# 不可修改内容

不复制 URI grammar、来源 registry、编辑器或上下文激活逻辑，不预写浏览器状态。

# 规范

Chromium 合同运行真实 Provider、Opener 和 HTTP 客户端，只替换宿主与 HTTP 回执；模型引用计数不作为实际文件读取证据。正式页面使用完整 Workbench、真实 Gateway 和独立工作区，准备普通 AGENTS 文件并核实际读回内容。沿正式镜像产物路径、端口租约、原 integration gate 和进程外保护。

HTTP Skill 页面通过原配置与真实来源建立 accepted 快照，记录启动获取和后续次数；本地 Skill 页面只准备固定根的普通文件，沿原 ResourceNavigation 一层metadata发现。发现、取消、原 SourceDocuments 打开不抓取上游、登记来源或编译 runtime。不可用HTTP来源保留原 error_code，不用保留正文冒充新快照，Gateway／插件 Skill 只消费原发布 metadata，经工作区代理固定目标及受众；发现不绑定来源或启动观察，正文打开沿原 Opener。inline 仍按原范围。

Provider 合同区分单次 provide 的本地筛选与重新打开的当前发现；取消要观察实际 AbortSignal，所有 owner 的 AGENTS／Skill metadata 共用三并发，不用跨生命周期缓存或第二套索引。

`agent_spec` 合同同时运行真实规范 URI Opener／HTTP 客户端，在解析、路由、main Thread 和模型取得的具名服务边界改变身份，包含 Gateway 离开后切回，核迟到打开拒绝、引用释放及零空分屏；复制同样拒绝切回后的迟到结果。正常文件／精确 child／Session 保留同一打开选项。不把这些宿主边界当真实身份撤销产品验收。

首次来源聚焦合同运行真实 Provider 与原 QuickAccessController，只替换 Picker 宿主和具名 HTTP 回执，核加载行不阻止首次真实候选聚焦、按 ID 续焦、原目标消失不改投及单选／多选取消零交付；正式 AGENTS 页保留 Enter 与 Alt+Enter 打开断言。二级范围选择核原 picker 释放后 Gateway 离开并切回仍拒绝恢复旧来源。

配置复制合同执行同一资源 Command／URI parser 和正式来源目录客户端，分别核候选直接复用 URI、编辑器只查原目录、无 URI 逻辑来源拒绝，以及身份失效；HTTP 回执与剪贴板宿主为具名装具，完整 JSONC 页面继续负责真实 Gateway 接线及原保存回归。

运行资源合同实际调用 Provider、Command 及原 HTTP 客户端，显式宿主／回执装具不能冒充真实 Gateway。正式运行资源页面通过产品 API 创建 Session、终端与 Browser，核独立 stop／detach／delete、所选 revision 冲突、原底部面板按钮和明确工作区；不预写账本或触发模型执行。

同页右侧 Session 场景在真实 GET 前通过原 promote 发布新版，不替换响应；验证旧版本拒绝、原 loader 刷新后解除精确 Thread 关联。强制刷新卸载资源行后重新展开；结束 Browser 预览再进入独立 B 管理场景，避免 attach 页重建期间的焦点切换干扰。

配置合同运行真实 ResourceQuickAccess 与配置 API，命令宿主只捕获冻结的来源和编辑器选项；验证同 Gateway 去重、工作区隔离、取消、分支权限及零提前正文读取。完整打开、侧开、原 JSONC writer 保存、只读、冲突和草稿恢复由 `test_settings_source_editor.py` 的正式 Workbench 页面覆盖，不把合同装具当产品验收。

变更合同运行原 Provider，HTTP 与编辑器宿主为具名装具；核明确 Session、入选工作区、摘要零正文、冻结 child／组／changeset 与取消。正式 `test_change_documents.py` 通过产品执行生成更改，经 resource 目录选择后进入原面板／Diff／补丁；不预写 changeset 或浏览器展示态。

附件合同复用原 Provider，核精确 Thread、独立上传、显式分页及关闭后的迟到结果；浏览零原件读取。正式附件页面通过消息产品入口生成文本与非文本附件，接受后进入原预览，分屏／刷新沿原展示态，不预写历史或浏览器存储。

同页附件候选直接复制文本与 PDF 的原 URI，核真实剪贴板、唯一 parser 的 owner／request_id、选择器焦点与零原件读取／新 Tab。合同另核跨 owner 焦点变化、归属错误和凭据失效零剪贴板写入；续页按钮使用共用候选的实际 label，不复制已删除的专用按钮名称。

同一正式附件页从候选把文本与 PDF 引用追加到原 Composer，并核刷新恢复、零新增消息／模型执行及预览前零原件读取。原 Provider／Command 合同用真实 ThreadPane 子类和具名草稿 writer 边界覆盖焦点改变、接收者关闭／未就绪、凭据失效，以及全局明确选择／取消；不将边界装具当真实跨工作区页面。

Session 分支页面经产品消息生成来源，再从未打开 Thread／Session 候选及原导航菜单取消，核零 fork 写入；完整历史复制发布 durable child 后，由 child 的原命令面板核精确来源。模型回放仅一次用于准备来源历史，不预写检查点或浏览器业务状态，不代替 Windows／真实远端／Electron 验收。

Thread 引用页面经产品消息及 fork 创建 main／child，再从最近候选复制精确 URI；Composer 沿原文件多选只加入未打开文件的引用。核实际剪贴板、原 request_id、零额外正文读取和零新增执行；跨 Gateway 与错误归属由具名 HTTP／宿主合同装具验证，不把本机页面称为真实远端验收。

工具结果页面先经产品消息生成来源历史，再用原 fork 入口创建 child，并由 child 实际执行工具；不能用来源摘要冒充 child 的原工具行。发现按公开 metadata 的 `invoke_extension_tool` 标识，取消零正文读取，接受沿原 around 定位并展开原 ToolRow，核 owner／revision／canonical item／Turn／tool_call_id／request_id 及零重放。Backend 与 Gateway 共用该场景隔离 Home，普通业务验证复用已准备的不可变插件包，并沿正式绑定入口启用能力。

来源多选合同同时执行原来源 Provider、Composer Command 和 URI 客户端，仅替换 HTTP／Picker／writer 的具名边界；覆盖跨 Gateway 来源、Gateway 配置、发起 child 附件、独立范围、两阶段取消与身份／接收者失效。真实 Composer 页面另核工作区 B 的 AGENTS／Skill 从未打开即加入 A 草稿及刷新恢复；不能把合同装具称为真实跨 Gateway 或 Electron 验收。
