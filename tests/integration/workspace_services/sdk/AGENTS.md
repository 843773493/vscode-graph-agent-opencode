# 目录用途

验证已构建 SDK 与完整插件制品在独立目录的真实进程、HTTP 和生命周期行为。

# 可修改内容

- 独立 SDK 插件测试资产及离线制品集成测试。
- 从原构建 fixture 复用包内依赖的测试接线。

# 不可修改内容

- 不复制产品实现，不以源码路径或开发环境补齐制品依赖。
- 不修改实际插件业务来制造维护需求。

# 规范

- 子进程使用 `-S` 和明确的制品内 `PYTHONPATH`；独立插件审计钩子拒绝产品导入及非本机网络，Backend 只读取正式 application 清单和制品依赖。
- 正式产物按测试文件路径写入 `out/tests/integration/workspace_services/sdk/`。
- 测试必须带进程外超时与内存保护，保留进程原始输出和来源证据。
