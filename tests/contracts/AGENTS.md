# 目录用途

存放跨进程、跨语言稳定协议的契约测试，包括 API、客户端协议和工作区辅助服务协议。

## 可修改内容

- schema、生成类型、请求/响应、SSE、认证和代理边界测试。

## 不可修改内容

- 不要验证完整用户流程；这类测试属于 Integration 或 E2E。
- 不要用客户端截图代替协议断言。

## 规范

- HTTP批量descriptor漂移经共享`openapi_export` fixture调用真实`export_openapi_snapshot.main`，每次读取当前候选文件，保留逐用例异常原件及已有快照字节；不缓存校验结果。批量检查的证据为进程内真实导出，独立冷CLI的成功／validate-only、Workspace历史拒绝和Gateway运行组拒绝仍使用真实子进程，不将两者混称。快照准备统一使用`openapi_output`，每个测试仍独占输出目录。
- 契约断言必须面向公开边界，不依赖内部类或私有实现。
- `test_runner_cli.py` 同时核对矩阵 CLI 和 Bun 测试发现边界；仅在隔离哨兵项目中验证 Web／Workbench 自有测试会执行，固定上游、参考仓库和生成产物不执行，绝不运行真实上游测试。
- Agent HTTP 结构核对四个真实路由的请求、列表及详情响应、嵌套 Provider 和候选 descriptor 漂移；导出产物只写入隔离输出，不改写客户端快照。
- 会话生成器 HTTP 结构核对实际预览／定义校验的请求和响应、字段漂移及候选 descriptor 的发布前拒绝；与其它 Workspace HTTP 契约共用独立 OpenAPI 副本 fixture，产物按本测试文件写入 `out/tests/`，保留 Pydantic 命名与策略约束。
- 运行时 HTTP 结构核对状态、排空／取消／强制中断及快照回执的实际响应，覆盖阻塞资源的嵌套字段与候选 descriptor 漂移，保留生命周期业务约束。
- 失败必须明确指出不兼容字段或行为。
- 工作区信息、上下文和索引核对真实 HTTP 响应引用、结构漂移及候选 descriptor 的发布前拒绝；只写隔离导出产物，元数据的 URI 与正文边界复用原序列化回归。
- 会话文件变更核对实际列表、详情及审查路由，递归检查汇总和文件成员，并验证候选 descriptor 的根或嵌套漂移在发布快照前拒绝；导出只写隔离产物，保留 URI 和业务校验。
- HTTP 结构测试共享包含 Workspace／Gateway 及其依赖的 descriptor fixture；Gateway 目录链的测试核实际路由、递归结构、保留的业务校验和发布前失败，不读取或改写客户端源码中的快照。
- Gateway 受管工作区链覆盖本机与联邦的真实 OpenAPI 请求／响应引用、嵌套成员及候选 descriptor 漂移；以隔离输出验证发布前拒绝，不启动 Gateway 或工作区生命周期。
- Gateway SSH 连接列表和远端连接请求核对真实 OpenAPI 引用、根缺失及嵌套字段漂移；候选 descriptor 不匹配须在发布快照前失败，保留导出命令、原始输出和退出码。连接来源和端口等业务校验复用原 SSH 回归，不另建公开字段映射。
- Gateway 端口转发覆盖六个控制路由的完整列表响应、三个请求根、嵌套成员及候选 descriptor 漂移；保留端口范围、协议和标签等业务校验，发布失败不得改写原有快照。
- Gateway 用户与访问租约核对七个控制路由、三个请求根、用户与租约嵌套结构及候选 descriptor 漂移；保留名称、跟踪值和访问类别的业务约束，发布失败不得改写原有快照，不涉及客户端视图状态。
