# 目录用途

存放 Node SDK 的公开 ESM 入口、运行实现与包内资源。

## 可修改内容

- 与 SDK exports 对应的 TypeScript 实现、公开类型和只读资源。

## 不可修改内容

- 不包含 Gateway 安装管理、插件业务 owner 或客户端代码。
- 不手工编辑生成协议目录。

## 规范

- SDK 公共能力只保留一份实现，消费者从公开包路径导入。
- 新增源码子目录必须含四段式 `AGENTS.md`。

- 手写模块的相对运行导入使用 `.js` 后缀，由同一 TS 源构建；声明只在发行构建生成，不维护 `.mjs`／`.d.mts` 对。协议仍使用现有生成器。
