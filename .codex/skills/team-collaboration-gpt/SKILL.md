# GPT 团队协作

主模型由用户选择 GPT 系列；技能不能切换正在运行的主模型。

先读取[共同调度流程](memory/2026/10/08/team-collaboration-workflow.md)，继续实施时读取[实时状态](memory/2026/10/08/team-collaboration-state.md)的当前收据与队列。人数、目录、Git和派单合同只在共同流程维护；模型配置只在本入口维护，不写入 AGENTS.md。历史台账按当前 task 查询，不全文重复恢复。

创建 subagent 时显式传入：

```javascript
start_delegated_task({
  task_name,
  model: "gpt-6-luna",
  reasoning_effort: "max",
  fork_turns: "none",
  message,
});
```

模型 ID 不带 provider 前缀，不能省略或改成 newapi-local/gpt-6-luna。创建、回复及 turn_context 已通过[只读探针](../../../out/tests/temp/2026/10/03/154301-gpt-model-probe/coordinator/artifacts/model-probe.json)。工具候选列表不单独证明某 ID 不可用；真实失败记录原错误，不静默换模型。复用先确认实际模型与 effort，follow-up 不能换会话模型。

## 当前授权与效率比较

本轮按用户授权，一个 **gpt-6.1-sol/max** subagent贯穿核心实现，**gpt-6-luna/max** 负责独审及实证小修；覆盖默认配置。创建与实际turn_context已核，不为人数制造重复实现。Sol独占ROOT核心，Luna仅在规定数据盘代码worktree改明确的小范围，不接大型或核心重构。主代理维护规范/技能、固定交付与串行集成，不手写业务源码；先核Sol租约、文件/方法及测试依赖，再派Luna。受保护面和其它owner独占面继续有效。

用户要求整批实现：同一完整调用闭包一次迁齐源码、调用方、DTO/协议和核心fixture；编辑快速静态，批末一次Webbuild。先跑少量真实核心入口、集中修共同前置，再迁边界fixture与补回归。最终整批停写后冻结、独审、集成；发现问题由原作者修完整受影响闭包，只增审差异。不能逐小包冻结或重复动态检验，不能把全历史fixture迁齐设为核心准入门。所有测试仍带进程外保护；已有通过结果按实际依赖复用，最终必要验收保留。

多个实现者有真实依赖时，公共合同由唯一提供者先交完整依赖；单个实现者的接口和消费者同批迁齐，不人为设中间门。修订交付引用既有固定树/清单，只列新差异和真实收据；主机械合成并核caller遗漏，不让作者反复重写全历史报告。比较完整候选耗时、入口遗漏、首次通过、返工与依赖等待，继承投入、主补救及caller接手单列。没有同起点Sol/Luna A/B，不宣布速度倍率或永久最优。

## 严重失败与纠正

只保留影响下一次派单的原因和做法；具名证据、技术条件及未验证效果查[条件性细则](memory/2026/10/08/delivery-failure-rules.md)，按当前任务关键词读取。

- **微包和重复检验拖慢交付。** 一次授权完整闭包，核心修通后集中边界，最后停写交付。批末统一Webbuild，不为测试fixture重复整应用构建；后续队列逐项认领原需求，不能把未实现业务藏进“最终验收”。
- **手工补丁、并发合同和live差异漏交付。** 从固定Git树机械导出、严格重建、核全调用方与运行时模板；完整diff-check包含新增文件。禁Git写的作者只交停写文件/SHA和真实raw收据，主代理导补丁，不让作者反复手工拼补丁或重写报告。固定blob串行集成，不能add作者live、裁补丁或用陈旧索引提交。
- **helper绿灯漏真实装配和持久事实。** 核真实准入、Provider/工具、下一请求与恢复；有SQLite owner合并/CAS时核同次写入范围和重开读回，JSON夹具或内存列表不能代替。替身只放外部传输边界。公共fixture缺必填字段、旧签名/间接参数或子进程字符串时集中迁齐，不放宽断言；生成器全部暂存成功后再替换输出。
- **冻结与当前状态混用。** fork/replay/rebase使用原owner的权威cut和版本证明，不从当前源重建历史正文。CAS失败保调用方已持有的旧对象；跨owner不重入同一锁。
- **观察入口通过但生命周期漏接。** 一起核CRUD、runtime替换、最后成员合法空目标及恢复；同一合法删除分别核在线与停机，不能要求先启动旧组。转发等清理可能失败时，清理成功前不删除权威登记。旧close旁路须下线；TTL不能证明holder停止。恢复同一generation保完整启动清单及辅助地址，真实Web核自身SSE释放/恢复。事务及初始化异常测试核原异常和后续公开访问；清理成功保原重试语义，失败隔离坏连接，不能手工rollback替生产清理。
- **Luna小修夹带框架或缩窄输入。** 只修已复现直接闭包，保原合法输入和异常原因，不新增冻结/事务框架。37 mixin、平行状态表等未实证风险不交Luna大改；无具体finding及时收尾，不为填并发槽制造探针。
- **路径漂移和失败后扩大写入。** 每命令固定物理cwd、任务根及私有index环境；批量操作失败即止，静态命令不能带空路径。Git创建worktree，正式测试从代码根执行；清理只核已知候选/真实数据叶与已证明进程，保raw和独有源码，不宽搜整仓或复用旧业务工作区。
- **虚绿和外部阻塞误导状态。** 每attempt独立保存actual/raw/SHA再汇总，避免并发覆盖台账；核selector真正覆盖新增node，遗漏只补精确node。量化核操作、样本、统计量，GET median不能当mutation p95。相同quota失败不重复求绿；取消同目录正文加密不改变联邦/SSH/认证及Provider opaque reasoning合同。

具体技术失败按关键词查询[条件性细则](memory/2026/10/08/delivery-failure-rules.md)，当前结果与待完成项只在[实时台账](memory/2026/10/08/team-collaboration-state.md)维护。严重失败先纠正派单，再窄改规则；后续真实交付验证后才记有效，无效或重复规则删掉。历史事故不自动成为全队前置；窄闭包通过不勾整个 change，不结束原 goal。文档提交后的 HEAD 只记外部收据，不追逐自身坐标反复提交。
