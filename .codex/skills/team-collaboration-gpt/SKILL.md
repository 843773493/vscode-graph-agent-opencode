# GPT 团队协作

主模型由用户选择 GPT 系列；技能不能切换正在运行的主模型。

先读取[共同调度流程](memory/2026/10/08/team-collaboration-workflow.md)，继续实施时读取[实时状态](memory/2026/10/08/team-collaboration-state.md)的当前收据与队列。人数、目录、Git和派单合同只在共同流程维护；模型配置只在本入口维护，不写入 AGENTS.md。历史台账按当前 task 查询，不全文重复恢复。

创建 subagent 时显式传入：

```javascript
start_delegated_task({
  task_name,
  model: "gpt-6-luna",
  reasoning_effort: "max",
  fork_turns: "none",
  message,
});
```

模型 ID 不带 provider 前缀，不能省略或改成 newapi-local/gpt-6-luna。创建、回复及 turn_context 已通过[只读探针](../../../out/tests/temp/2026/10/03/154301-gpt-model-probe/coordinator/artifacts/model-probe.json)。工具候选列表不单独证明某 ID 不可用；真实失败记录原错误，不静默换模型。复用先确认实际模型与 effort，follow-up 不能换会话模型。

## 当前授权与效率比较

本轮按用户授权，由一个 **gpt-6.1-sol/max** subagent贯穿核心实现，**gpt-6-luna/max** 负责独审及不干扰Sol的边角修复；覆盖上述默认配置，不为人数制造重复实现。实际创建与turn_context已核。Sol独占ROOT核心源码与受保护测试；Luna窄修在规定数据盘worktree中独占明确方法与独立测试，禁止大型或核心重构。派单先核Sol文件/方法和测试依赖，已实证小缺陷一次修完整闭包，无实证结构风险只调查。主线程维护规范/技能、核验固定交付并串行集成，不并发改业务源码或占作者正式测试工作区。同文件并发改动按固定blob集成，禁止add作者live吞入另一方在途修改；Luna改动在相关Sol验收前给出完整依赖与真实收据。保护路径与其他owner独占面仍有效；caller接手和主补救成本单列。

以当前已授权的完整调用闭包为一批，一次迁齐全仓必要源码、调用方、DTO/schema和核心所需公共fixture；编辑时做快速静态分析，批末统一复核。先用少量现有真实入口修通共同装配与核心业务，再集中迁移其余unit/边界fixture并补回归，不能把全历史测试迁齐设为核心准入门。同一公共前置挡住多个用例时先集中修正，定向确认能通过该前置后再展开整组，不让每例重复等待同一错误。已绿且依赖未变的检查复用。实现中不逐小包冻结、不逐文件申请授权、不每改一点就跑动态测试；同一作者整批停写后冻结完整候选，独审缺陷修受影响闭包，保原候选，只增审差异。多个审查者分别主审明确主题；必要的跨主题依赖引用其主审证据，不各自重审。已有可行动结论立即回报，短报告的行号、统计或完整任务映射不阻断后续核心批次。修订交付只列本次完整变更与实际收据，引用既有固定树/清单；主机械合成完整候选并核遗漏，不让作者反复扫描全部旧raw和重写全历史大报告阻断实现。测试始终带进程外保护，最终必要验收保留。

分工按实践调整：单个实现者负责的公共接口和消费者同批迁齐，不设中间交付门；多个实现者存在真实依赖时，公共接口由唯一提供者先交完整合同，再推进消费者。每个相近闭包比较首个完整候选耗时、真实入口遗漏、必要测试首次通过、返工、依赖等待及主补救量；接手前投入单列。当前没有同起点可比数据，不宣布Sol速度倍率或永久最优模型。

## 严重失败与纠正

只保留影响下一次派单的原因和做法；具体事故、具名证据与验证限制在[条件性细则](memory/2026/10/08/delivery-failure-rules.md)按任务查询。

- **微包调度和重复检验拖慢交付。** 完整调用闭包一次授权、迁齐、核心修通、集中边界、最终停写交付；已有检查按实际依赖复用。后续队列逐项对应原需求，不能把尚缺业务实现并入“最终验收”而漏派。
- **手工补丁和多个作者同时改合同造成遗漏。** 审查先交固定对象与manifest/SHA，不能用作者仍在写的活树代替基线。补丁从固定 Git 树机械导出、严格重建并核直接/间接 caller，包括实际分发给模型的运行时技能、提示模板和工具说明；唯一作者同时迁公共接口与消费者。私有索引也会陈旧，集成固定 blob、串行提交，不能 add 作者 live 或切补丁文本。
- **helper 绿灯漏真实装配和持久事实。** 少量核心贯穿真实准入、Provider/工具、下一请求与恢复，并核 canonical/extension、来源及冷投影。真实清单/复合视图的辅助服务依赖按实际 callee 一次装齐；角色判定读取权威角色，不能用已注入但为空的目录对象代替。新进程用例复用当前配置 schema 与 HTTP 异常映射，先核必填输入和预期状态码，保留实际恢复与隔离断言，减少因测试合同猜测而重复启动。下线签名同时迁 fixture、间接参数和子进程程序字符串，不加别名或弱化断言求绿。生成器先在规定暂存根完整生成成功，再替换输出，外部失败不能先删可用绑定。
- **冻结、当前状态与截断混用反复返工。** fork/replay/rebase 一起核 contribution、selection、detail、prefix 与目标身份；使用各自唯一 owner 的权威 cut 和版本证明，不从当前源重建历史正文。锁内冻结对象传递，跨 owner 避免重入同一锁。
- **通过观察入口仍漏生命周期边界。** TTL 不证明 holder 已停止；GC 须由原 owner 在同一事务核 generation/终态并清相关记录。恢复按目标实际 lifecycle 与准入事实推进，已 ready 的新进程不再执行旧 drain 的取消动作。取消、确认失败和 unknown 分开；真实提交前失败与冷重开须保留证据。
- **小修夹带新框架或缩窄合法输入。** Luna 只修已复现的直接闭包，使用原合同接受的 Mapping/list/tuple 等输入，不添加额外 hash/冻结体系。异常同时核 adapter 和 pending 消费者的原始原因；37 mixin、平行状态表等未复现结构风险不交 Luna 大改。只读调查无具体合法输入候选时立即无 finding 收尾，已有真实响应证据先复用，不为填满并发槽重复探针或制造分支。
- **路径漂移、批量工具失败后扩大写入。** 每命令固定物理 cwd 和分配根；失败即停止，静态修复只接收非空闭包路径。新 worktree 用 Git 创建，不复制历史运行数据；正式测试命令从代码树根运行，业务 workspace 只作被测目标。清理核真实镜像层级和内容；名为 runtime 的测试父目录不等于 run-* 数据叶，先核并结束已证明归属的写入进程，保 raw 和独有源码。Git 禁令包含 status，陈旧 D/?? 不证明源码丢失；核可复现且已集成后清理。
- **虚绿与外部阻塞误导进度。** 每 attempt 保原始输出和实际退出码；超时、截断、缺 raw 不计通过。量化先核操作、样本与统计量，目录 GET 的 median 不能当 mutation 的 p95，源码推断不能当运行重载或并发丢失更新结果。相同外部 quota 前置失败不重复求绿，继续独立工作。用户已取消本地同目录正文加密，保原联邦/SSH/认证及 Provider opaque reasoning 合同。

具体技术失败按关键词查询[条件性细则](memory/2026/10/08/delivery-failure-rules.md)，当前结果与待完成项只在[实时台账](memory/2026/10/08/team-collaboration-state.md)维护。严重失败先纠正派单，再窄改规则；后续真实交付验证后才记有效，无效或重复规则删掉。历史事故不自动成为全队前置；窄闭包通过不勾整个 change，不结束原 goal。文档提交后的 HEAD 只记外部收据，不追逐自身坐标反复提交。
