## Why

同一次故障在日志、实时消息、历史查询和前端提示中经常变成不同解释：已有异常原因被缩成类型或单个失败状态，页面再凭状态生成兜底文字。需要贯通各业务 owner 的错误交付，而不是为每个字段写提示、为每个函数添加 `try/except`，或建设第二套错误平台。

## What Changes

- 复用现有公共 `boxteam.common.v1.Error(code, message, details)`、错误出口、SDK 日志与关联上下文，固定最小字段合同；未知异常也可交付，不依赖逐种错误登记或人工编写文案，不替换标准协议信封。
- 在现有 HTTP、后台执行、进程管理、协议调用和客户端异步操作边界报告失败；业务内部继续正常抛出异常，不机械包裹所有函数。
- 保留错误产生层和失败操作，区分业务失败、传输失败、用户取消及结果未知；Gateway 透传下游事实，只为自身产生的故障提供解释。
- 按 owner 贯通聊天、受管插件及安装、MCP、主题、配置、终端／浏览器／调试资源、维护与关闭的错误链路；各模块继续维护自己的状态和已有存储，不合并成聊天记录或全局错误库。
- 聊天失败以原 rollout convergence 终态提交为唯一持久来源，同事务提交状态、failure 和历史 revision；Job 启动恢复先查已提交结果，再决定恢复、丢失及 Trace 收尾，消息流沿同一来源补齐，不为已结束执行追加相矛盾的 execution_lost 或重放执行，不新增 outbox 或恢复服务。实时、快照、历史 summary/detail 消费同一事实；有错误时不再固定显示“后端没有提供详情”。
- 模型回退或工具失败后继续成功时，失败保留在原 attempt 明细，不升格为 Turn 失败；新 execution 不继承旧 execution 的失败。
- 普通异常优先保留已有原因，校验错误按类型通用提取，HTTP／MCP／子进程沿原协议保留状态和错误。项目构造的公共错误及展示摘要整体 JSON 默认至多 16 KiB，message 至多 8 KiB，并限制问题数、子错误数及深度；原更严格预算优先。HTTP／MCP／DAP 原始载荷仍沿原传输规则，Gateway 不为摘要预算缓冲、解析或重写下游正文，不全量扫描日志。
- 本链路公开载荷及产品生成的格式化堆栈均在原出口脱敏；凭据来源仅限使用边界当次已持有值，不建立秘密注册中心，不同时记录 raw traceback。主题错误展示保留原生预览取消、主题移除和启动恢复规则，不把此次切换失败宣称成功。
- 诊断在格式化过程中限量：默认单条正文至多 64 KiB、堆栈帧合计至多 64 帧，原因数量／深度复用公共上限；超限明确省略，不先生成整份诊断再截断，不用日志轮转代替构造预算。
- 补充少量跨层契约与真实入口验收，验证失败原因在刷新／重连后不变、原始凭据不泄露、清理失败不伪报成功及交互延迟不退化。

## Capabilities

### New Capabilities

- `failure-reporting`: 项目通用错误交付语义、执行边界、跨进程传输、诊断关联、敏感信息处理及按 owner 的前端展示规则。

### Modified Capabilities

- `session-turn-history`: 历史摘要与详情保留原执行失败事实，缺失原因明确表示未记录，不由前端猜测，不扫描 Trace 或日志补齐。
- `turn-message-stream`: 实时失败、恢复快照与历史终态交付一致的原因及已有作用域关联，保留取消、超时和结果未知的原语义。

## Impact

- 公共边界：`app/core/failures.py`、`app/core/trace_middleware.py`、`app/api/errors.py`；复用而非叠加 formatter、异常装饰器或报告服务。
- 协议：复用 `proto/boxteam/common/v1/error.proto`，按实际缺口更新各领域原 DTO／protobuf 与生成消费者；不强制所有领域重命名现有 error 字段或替换 HTTP／MCP／DAP 等标准错误信封。
- 聊天：执行收尾、原 rollout／message stream 写入与投影、历史 API、React 状态及 Turn 展示。
- 管理面：Gateway 插件实例／安装操作、MCP 连接与调用、配置候选、主题加载、资源 owner、SDK 后台维护和生命周期关闭，原重试、释放资格和状态机不变。
- 客户端：Web／Electron 共用 Workbench、React 管理界面和已有 HTTP 错误解析；浏览器本地异常使用客户端既有日志，不伪造后端 request_id。
- 不新增监听端口、常驻连接、轮询、数据库、错误事件总线、遥测平台或用户配置开关；不因错误展示改造触发真实用户配置修复、历史重建或全库迁移。
