## Context

见 proposal.md。现有 session-turn-history 对 reader 有更严格的局部预算；trace middleware 已有 request_id 和 duration。当前测试矩阵的进程期限用于防挂死，不是用户操作的 SLO。新验收直接使用现有正式 Workbench 构建、隔离 Gateway 和托管 Backend，不增加生产监控。

## Goals / Non-Goals

**Goals:** 普通请求及操作有完整总账；超慢单次请求不能被平均值掩盖；性能证据同时证明结果归属、真实内容和成功状态。

**Non-Goals:** 本轮不重写存储校验策略、不改缓存或业务契约、不调环境来掩盖失败；不将 Chromium E2E 冒充 Electron 验收。

## Decisions

### 1. 总延迟与局部预算同时成立

本机回环、服务已就绪、无外部 Provider 的小型请求从客户端发起至完整正文消费计时；包含 Gateway、Backend、排队、鉴权、校验、磁盘读取、内部重试和序列化。本轮用该上界约束软件处理成本，不减去“完整性检查”等内部耗时。首次真实数据读取单独记录；20 次暖样本记录原始值、nearest-rank p50/p95/max，零自动重试、零删异常值。

| 范围 | p95 | 单次硬上限 |
|---|---|---|
| 普通本地业务 API，响应不超过 512KiB | 500ms | 1500ms |
| 导航组合：工作区列表＋当前工作区＋目录投影 | 1000ms | 2000ms |
| 已就绪 Workbench 的搜索接受到正确会话输入框可操作 | — | 2000ms |
| 原版文件编辑器接受打开到正文可见 | — | 2000ms |
| 首次未缓存业务数据读取 | — | 3000ms |

局部历史 reader 的 100–200ms 合同继续有效，不能以总预算更宽为由放松。构建、安装、进程启动、首次 Workbench 静态资源加载、真实外网／模型响应和明确用户等待分别报告，不混入普通请求样本，也不能在请求计时开始后把慢的初始化剔除。浏览器等待期限比预算略长仅便于保留完整失败证据，断言仍使用上述预算。

### 2. 三条代表性真实链

- 导航：32 个真实 API 创建的 Session、128 个普通文件；真实 Gateway 初始化三接口及目录 export，核归属和目录包含已创建对象，20 次组合暖读。
- 会话：选中其中两个不同 Session，原 Quick Input 接受并实际打开 Thread EditorPane，核 bootstrap owner／request_id 及 Composer 可操作。交替重新打开，按操作总耗时断言。
- 文件：128KiB 普通文件，经后端 URI 和原 boxteam-file 投影在原 Monaco 编辑器打开，核文件内容、原网络读取、正文传输量及 DOM 节点规模。

页面初始化可能已经预取目录，因此测试中的 `firstReadMs` 仅代表建好数据后首次显式目录读取，不证明底层存储冷缓存。真正冷读取须用明确的首次访问／受控重启边界另验，不通过清空缓存或静默重试制造漂亮结果。

这三条不调用模型。大规模 128 Turn 混合历史的现有确定性 Integration 仍由原测试负责，新增用例不能被宣传成已证明该场景；后续需在同预算框架补真实长历史 Gateway 读取，明确保留为待办。

### 3. 检查放在正确边界

请求边界保留鉴权、owner、输入、CAS、版本和本页数据必要校验。全数据库 integrity_check、全历史 JSON/hash 重算、所有 blob 枚举和无变化 schema 的重复全量证明只能由初始化／迁移／恢复／显式诊断 owner 有依据地执行；暖读复用由同 owner 持有且按版本失效的已验证事实，不能缓存可变业务成功状态、吞错或返回旧值。异常或变化时按原合同校验／拒绝，不为了速度取消完整性约束。失败先用 request_id 与原 trace 定位真实阶段，再迁移对应整条链，不加又一层防御 wrapper。

### 4. 长期审查记录

docs/openspec-performance-review.md 是人工查看入口，按需记录检查时间、源码位置／版本、事实／待证疑点、影响、最小复现和建议。只有显著新发现追加条目，同一问题更新原条目；不要求定时检查。审查只读产品代码／规范、维护该文档，最多运行定向受保护验证，不启动全套测试、不改服务或配置、不自动修产品代码。

## Risks / Trade-offs

- [机器负载可影响绝对耗时] → 保留负载和原始样本，报告环境／排队；不自动重跑取最好值或调大预算。
- [小目录不暴露深历史问题] → 明确本轮数据规模，保留长历史 Gateway 场景待办，既有长期历史指标不降级。
- [宽松测试 timeout 掩盖交互慢] → timeout 只兜住进程，独立操作计时与断言为验收依据。
