# gateway-user-access Specification

## Purpose
为通过 Gateway 使用同一工作区的用户提供无密码但可区分、可占用和可接管的前端访问身份，并为自动化测试提供不会污染普通用户状态的游客身份。
## Requirements
### Requirement: 普通用户身份生命周期

Gateway SHALL 允许用户创建、选择和删除普通用户身份；普通用户必须具有稳定且唯一的 `user_id`，显示名称不得作为身份或目录定位依据。

#### Scenario: 创建普通用户

- **WHEN** 用户提交合法的显示名称并创建身份
- **THEN** Gateway 创建稳定的 `user_id`，返回用户摘要，并为该用户准备独立的用户目录

#### Scenario: 选择未占用用户

- **WHEN** 用户选择一个没有有效访问租约的普通用户
- **THEN** Gateway 创建访问租约并返回该用户的前端视图会话

#### Scenario: 选择已占用用户

- **WHEN** 用户选择一个存在有效访问租约的普通用户
- **THEN** Gateway 拒绝普通选择并返回占用设备、最近心跳和占用时间等可展示信息

#### Scenario: 删除用户

- **WHEN** 用户请求删除一个未被当前访问租约占用的普通用户
- **THEN** Gateway 删除该用户的可选身份和用户视图数据，并明确报告用户目录的处理结果

### Requirement: 单用户访问租约

Gateway SHALL 保证同一普通 `user_id` 同时最多存在一个有效访问租约；租约必须通过心跳续期，并在超过过期时间后自动失效。

#### Scenario: 心跳续期

- **WHEN** 已登录客户端在租约有效期内发送心跳
- **THEN** Gateway 更新该租约的最后心跳和过期时间，且不创建第二个租约

#### Scenario: 客户端异常退出

- **WHEN** 客户端停止心跳并超过租约过期时间
- **THEN** Gateway 将该用户标记为空闲，后续客户端可以选择该用户

#### Scenario: 过期租约不可继续访问

- **WHEN** 客户端使用已过期的用户访问会话请求 Gateway 用户视图或工作区代理接口
- **THEN** Gateway 返回明确的用户会话失效错误，并要求客户端重新选择用户或游客访问

### Requirement: 用户接管

Gateway SHALL 为已占用的普通用户提供显式接管操作；接管必须使旧访问租约失效，但不得停止工作区后端中已经运行的 Agent 任务。

#### Scenario: 接管已占用用户

- **WHEN** 用户确认接管一个显示为占用状态的普通用户
- **THEN** Gateway 原子地使旧租约失效、创建新租约并返回新客户端的用户视图

#### Scenario: 旧客户端收到接管结果

- **WHEN** 被接管的旧客户端继续发送请求或保持 Gateway 实时连接
- **THEN** Gateway 返回可识别的 `user_session_taken_over` 错误或关闭该客户端的实时连接，前端退出当前用户视图并显示接管提示

#### Scenario: 接管不影响 Agent

- **WHEN** 用户接管时工作区后端仍有该工作区的 Agent 任务运行
- **THEN** Agent 任务继续运行，任务完成状态可由接管后的客户端重新读取

### Requirement: 游客访问

Gateway SHALL 提供不进入普通用户选择列表的游客访问；游客身份不得作为长期用户身份持久化，但游客访问期间的追踪信息可以保留最多 7 天。

#### Scenario: 游客进入页面

- **WHEN** 页面选择游客访问或自动化测试未提供普通用户身份
- **THEN** Gateway 创建临时游客访问上下文，不创建普通用户目录，并允许前端正常访问工作区功能

#### Scenario: 游客追踪清理

- **WHEN** 游客追踪记录超过 7 天
- **THEN** Gateway 删除该记录及其仅用于追踪的配置，不影响工作区会话的 rollout 和历史数据

#### Scenario: 游客不污染普通用户

- **WHEN** 游客访问期间修改主题、布局或会话视图
- **THEN** 这些修改不出现在任何普通用户的视图中，且 Playwright 新建游客上下文时不依赖旧的普通用户本地状态
