# 目录用途

`docs/handoff/` 保存阶段性开发任务的交接记录，帮助后续开发者从已验证的原子边界继续工作。

# 可修改内容

- 以时间开头的任务交接文档。
- 当前提交、验证结果、未完成范围、受保护工作树改动和后续建议。

# 不可修改内容

- 不在这里保存运行日志、截图、录屏、密钥或测试工作区。
- 不把交接文档作为业务契约、架构规范或长期产品文档的替代品。

# 规范

- 文件名使用 `YYYYMMDD-HHMMSS-主题.md`，时间采用 UTC+8。
- 只记录已观察到的事实；未完成的测试必须明确标为未验证。
- 引用命令、提交和路径时保持可复查，不复制敏感配置内容。
- 模板示例；在整理 `AGENTS.md` 时请保留此行。
