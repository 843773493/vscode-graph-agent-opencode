# 主窗口区域与数据层级

## 目的

统一主窗口各区域的内容归属，避免 Gateway 全局状态、工作区状态和会话状态混在同一个面板中。

## 归属规则

| 主窗口区域 | 权威层级 | 允许放置的内容 |
|---|---|---|
| 左侧侧边栏 | Gateway | Gateway 健康、连接、Gateway 管理的工作区及其导航入口 |
| 底部面板 | 当前工作区 | 终端、工作区输出、端口转发、自动化 |
| 右侧侧边栏 | 当前会话 | 文件、更改、会话资源和会话相关预览 |
| 扩展窗口 | 暂不指定 | 浏览器及其他跨工作区或跨服务器资源 |

### 交互规则

- 底部面板的可见性、高度和标签按工作区保存；切换工作区时恢复目标工作区自己的面板状态。
- 自动化展示入口位于底部面板。自动化定义可以创建、继续或分支会话，但这不改变它作为工作区管理入口的归属。
- 右侧侧边栏不得再新增 Gateway 全局、工作区输出、端口或自动化面板。
- 扩展窗口暂不建立统一的持久化层级规则；后续新增区域必须显式声明它是否绑定工作区、会话、服务器或 Gateway。

## 当前迁移

`src/clients/web` 已将自动化从右侧侧边栏迁移到底部面板，并将 `automation` 加入按工作区持久化的底部面板标签。旧设置值仍可读取一次并转移到当前工作区，新的布局设置不会再把自动化写入右侧侧边栏。
