# 目录用途

存放会话 SSE 事件流的批次状态更新、关联会话刷新和 Turn 失效规划，供主 hook 编排连接生命周期。

# 可修改内容

- SSE 批次写入前端镜像状态的逻辑。
- 会话元数据、工作区会话列表刷新和 Turn 详情失效规划。
- 与上述逻辑直接相关的纯函数测试。

# 不可修改内容

- 不管理 EventSource 连接、重连计时器或 React effect 生命周期。
- 不定义后端协议类型的权威来源，不实现 UI JSX。
- 不吞掉后端错误；错误必须写入状态或继续抛出。

# 规范

- 纯规划函数和副作用更新分别放置，输入输出保持显式。
- 业务状态只以 API 返回和事件流数据为依据，不在本目录伪造成功状态。
- 代码注释使用中文，专业术语除外。
- 模板示例；在整理 `AGENTS.md` 时请保留此行。
