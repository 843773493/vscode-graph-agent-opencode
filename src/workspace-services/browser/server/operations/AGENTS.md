# 目录用途

存放 Browser 后端的页面动作、输入分发和操作排队；由 Session 或连接入口明确委派，不管理浏览器资源集合。

```text
operations/
├── browserPageActions.js            DOM摘要、元素ref、定位与工具动作
├── browserInput.js                  CDP指针、拖拽、按键及文本输入
├── browserOperationQueue.js         Session操作排队、序号和撤权检查
├── latestPointerMoveDispatcher.js   单连接连续移动合并与排空等待
└── *.test.js                        对应动作及输入合并的原单元测试
```

先区分业务操作与传输：Session通过操作队列安排动作并提供页面状态，连接入口用移动调度器合并尚未执行的连续移动。动作函数处理DOM或CDP，不拥有WebSocket封包、ACK、Chromium启动或持久化目录。队列通过注入的Session调用状态发布和保存，不另建Session状态或存储owner。

队列的`browserSession`是执行动作的BrowserSession资源宿主，不是聊天Session或传输授权身份。`serialOperationTail`只串联排队操作；`acceptedOperationExecutions`记录未结束的执行句柄，包含尚未开始的串行请求、并发请求、工具超时后仍执行的原脚本及页面恢复。多个句柄可以属于同一操作，集合大小不是业务操作数。`drain(timeoutMs)`以默认5秒的单次预算等待原集合，每批settle后继续复核后来登记的句柄，预算不重置；true表示集合已空，false仅表示等待超时。调用方必须据此决定失败，不能假报取消、清除原Promise或重发动作。关闭与版本撤销复用本入口，不另建计数轮询或无限等待链；拒绝新操作仍由宿主的关闭准入负责，串行尾部不表示全部并发动作结束。

指针移动调度器的`pendingPointerMove`仅保存尚未交给回调的最新事件；`drainPromise`表示整轮排空何时结束，供后续键盘/点击等操作等待，不是页面活动标记。`supersededMoveCount`只累计待处理事件被替换的次数，不表示动作执行次数。`close()`丢弃待处理事件并拒绝后续输入，已经交给回调的动作仍由其原owner结束；关闭不等于取消该动作。

输入控制器拥有当前CDP连接的拖拽监听器：先注册以接住启用确认前的事件；启用失败立即撤销本次注册并原样抛错，不能让失败重试积累监听器。拖拽完成或切换页面时，由同一控制器解除已启用的拦截。

页面元素ref归 `browserPageActions.js`；摘要与坐标检查按同一标签页的ref索引预留单调编号。索引刷新只改变当前可定位项，不回收已发出的编号；否则页面插入或替换元素后，旧ref可能指向另一元素。已有元素保留当前文档版本的ref，导航后的版本前缀使旧引用失效；ref是定位标记，不是列表序号或DOM位置。

摘要按DOM顺序收集到80个可见元素后停止逐元素样式和尺寸检查，再写入ref；隐藏元素不占名额，可见性也不改为“位于当前视口”。全页候选查询与正文提取仍有各自成本，不能把这项短路优化称为整份摘要恒定耗时。

摘要元素的`text`是`summaryLabelOf()`选择的标签：依次取aria-label、alt、title、value、innerText、textContent，先按原始值的真假短路，再归一空白并截取160个UTF-16单元。只有轮到正文来源才读取正文，纯空白但非空的高优先级标签仍归一为空，不向低优先级回退。它不是整页正文、可执行selector或元素身份；整页文本提取与ref生命周期保持各自归属。

坐标元素检查在一次同步页面执行内整理可读CSS规则，按原顺序供命中元素和各层祖先匹配；跨域CSSOM拒绝也只读取一次。规则不跨检查保留，下一次必须看到样式更新。只减少重复读取与选择器拆分，仍分别匹配各目标；直接、伪元素、继承、最终计算样式的结果归类保持。

# 可修改内容

- 页面读取、元素定位、工具动作和CDP输入转换。
- 操作顺序、授权版本检查、连续移动合并及对应测试。

# 不可修改内容

- 不放HTTP/WebSocket路由、消息封包或逐连接画面流控。
- 不管理浏览器集合、Chromium运行时或检查点落盘。
- 不增加旧路径转发模块、重复动作实现或另一套元素身份索引。

# 规范

- 使用ESM，相对导入直接定位现有owner；通用运行时常量仍归上层browserRuntime。
- 操作序号、传输授权版本和元素ref分别表示不同事实，不互相替代。
- 业务操作保留顺序；仅连续指针移动允许替换尚未交付的中间值。
- 测试随动作模块归组，涉及真实DOM的集成场景仍归tests/integration/workspace_services/browser。
