# 目录用途

存放标签页被动诊断与流统计派生，二者都不控制业务生命周期。

```text
diagnostics/
├── pageDiagnostics.js       标签页网络/控制台缓冲、请求实例关联与清空
├── streamMetrics.js         帧观察与逐连接回执快照的纯统计计算
└── streamMetrics.test.js    速率口径及Session快照接线
```

页面诊断独占有界记录，每个已登记页面独享一份；流统计只消费显式观察事实。先区分“谁记录事实”和“谁从事实计算”，不能把统计提取变成另一套采样窗口或连接owner。

# 可修改内容

- 页面诊断事件采集、有界保留、记录字段说明与读取。
- 显式快照的流统计计算及相应测试。

# 不可修改内容

- 导航成败、资源活动保护、页面创建关闭及持久化仍归 Session 和各自 owner。
- 不调用 Session，不维护导航状态或另一套请求身份。

# 规范

- 使用 Node.js ESM；页面诊断只依赖Playwright事件与无状态时间工具，流统计函数只接收值，不读取时钟或持有Session/连接句柄。
- 网络和控制台各最多保留200行；清空网络只断开旧请求关联，不回收记录编号、不清控制台。
- 请求按实际 Request 实例关联，HTTP 错误码不等于传输失败；具体字段语义在记录类型处说明。
