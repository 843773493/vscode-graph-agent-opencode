# 目录用途

保存 Terminal 恢复状态 owner 的显式格式转换。`v3_json_to_v1_sqlite.mjs` 是 schema 3 JSON 到 schema 1 SQLite 的命令入口；同名 `.js` 在原存储 Worker 中执行转换。

# 可修改内容

- 按来源版本、来源格式、目标版本和目标格式命名的转换及离线命令。
- 旧记录验证、原件保全与拒绝覆盖的原子发布。

# 不可修改内容

- 不复制现行 schema、SQLite 初始化或批次写入；复用原 Worker 的唯一实现。
- 不改变 PTY、领域资源 owner 或普通读写行为，不增加自动导入、旧格式双写或转发入口。

# 规范

- 这里的 3 与 1 分别来自源 JSON 的 `schema_version` 和目标 SQLite 的 `user_version`，不代表软件版本。
- 命令在终端服务已停止时显式运行；先核对工作区身份，目标必须不存在，源 JSON 保持不变。
- 转换在原 Worker 中同步执行，共享该次操作的阶段诊断；正文验证与原 SQLite 事务、收尾错误传播保持不变。
- 执行入口由原 Worker 显式登记，不按文件名发现或排序；打包必须包含命令和转换模块。
