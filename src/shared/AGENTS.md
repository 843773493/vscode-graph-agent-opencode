# 目录用途

存放跨客户端与辅助服务共享的 SSE 字节流处理、运行时消息校验及实时事件连接实现。

# 可修改内容

- `sse.js`、`sseRuntime.js` 及对应声明：SSE 字节流解析、帧边界、取消语义和运行时消息校验。
- `sseRuntimeValidators.js` 及对应声明：由唯一协议生成流程维护的运行时校验器。
- `realtime.js` 及对应声明：Workbench 与独立终端页面共用的事件连接 owner。

# 不可修改内容

- 不放入 Node 插件管理、日志、诊断、HTTP 或进程生命周期实现；这些公共能力由 `@boxteam/plugin-sdk` 提供。
- 不放入 Workspace 后端业务逻辑、页面组件或平台宿主代码。
- 不重新引入已移除的 VS Code extension、Webview API 或旧客户端协议。

# 规范

- SSE 字节流统一由 `sse.js` 消费，业务模块不得维护第二套分帧逻辑。
- 启用帧间让出时保留微任务交接；主线程让出按处理时间片执行并跨网络 chunk 累计，不逐帧创建定时器拖慢历史补读，取消后停止当前批次后续交付。
- `readError` 仅映射实际 reader 读取失败，默认保留原异常；已出错流不再次取消，所有收尾出口释放 reader 锁，取消失败保持可见。
- SSE JSON 必须通过 `sseRuntime.js` 的运行时校验器校验，不能只依赖 TypeScript 类型断言。
- 生成文件只能由协议生成流程覆盖；共享模块不得依赖具体客户端入口。新增源码子目录须包含四段式 `AGENTS.md`。
- `realtime.js` 是 Workbench 与独立终端页面共用的事件连接 owner：按入口 URL 共享 WS、订阅独立反压和取消；已取消调用不能先创建无人持有的连接。领域游标与凭据由调用方维护，不允许各业务复制连接实现。
