# 目录用途

主窗口底部面板的原生端口转发网格，复用 WorkbenchTable、ActionBar、输入框和上下文菜单。

# 可修改内容

- `model.ts`：Gateway 回执镜像、未提交的新行、行内编辑和启停。
- `renderer.ts`：原生单元格及悬停动作；`view.ts`：ViewPane、列布局、菜单和快捷操作。

# 不可修改内容

- 不拥有端口业务状态，不在浏览器创建隧道，不绑定激活工作区或 Thread。
- 不复制 HTML 表格、大表单或另一套转发 writer。

# 规范

- 后端完整回执是唯一业务事实；失败重读并在所属行的错误列显示。
- 每行固定高度；错误不纵向展开，参数在单元格内编辑。
- 使用原生主题、列分隔线、Hover 和菜单，停止保留规则，删除才移除规则。
