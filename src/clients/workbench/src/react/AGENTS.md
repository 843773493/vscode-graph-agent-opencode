# 目录用途

原生 EditorPane 中的 React 会话宿主、工作区面板及独立 MCP 授权入口，复用 Web 的业务产品。

# 可修改内容

React 挂载、释放、可见性、样式及浮层隔离；显式 owner 与原版编辑器服务之间的接线。

# 不可修改内容

不得复制聊天、任务或资源产品，不得创建第二套 API writer、状态机或调度器；不得导入旧 App 外壳。

# 规范

工作区、Session、Thread 显式传入；业务组件和样式来自既有 Web 源码，样式只作用于宿主 ShadowRoot；原版工作台布局、设置和快捷键由上游负责。

宿主主题复用共享图片预载与应用链路，加载失败通过原版通知服务显示警告并应用无背景图的主题；配置错误显示完整错误。主题切换和宿主释放取消旧加载的发布权，旧成功或失败回执不得覆写新主题或发布通知。取消发布不等于取消图片网络请求。

资源页复用会话资源 loader 的可见性轮询；隐藏、切换标签或释放 owner 时停止调度。没有运行时预览时必须传空槽，不能传入内部返回 null 的 React 元素而启用预览列。Gateway 生命周期操作复用既有完整组确认，控制中心不得遮挡业务确认浮层。

调试 Thread 导航通过原版 editor options 传递展开资源并选择调试的意图；新建与复用编辑器均应用该意图，保留其余展示态。

消息及子 Thread 资源的上下文分支复用 `useSessionForkDialog` 和会话实例已有的生命周期 writer；提交成功后按后端目标身份打开固定 Thread 标签。来源报告留在发起 Thread 的资源内，使用精确来源 Session、Thread、Execution，不以打开另一会话代替读取来源报告。

React 宿主隔离 wheel 冒泡，保留浏览器原生滚动，避免上游工作台根节点取消默认行为；不得用脚本滚动替代真实滚轮验收。

导航的 outbox 错误、初始化失败及显式操作异常通过原版通知服务显示，保留操作 ID 和诊断详情；普通状态不升级为错误，不靠匹配状态文案推断严重程度。

Thread 的浏览器视图、历史缓存及设置同步错误显式交给原版通知服务，并携带 Session／Thread 身份；Composer 的停止、草稿和设置操作错误保留在所属输入区。不得仅输出控制台或借用已删除的旧状态栏，不重新展示已移除的事件流重连状态提示。

资源页打开调试、子 Thread、原生更改审阅及消息引用文件的异步拒绝交给同一 Thread 的错误出口；文件预览与调试操作已有的局部错误继续由原组件呈现，普通进度不升级为错误。

原版活动编辑器切换时使尚未完成的会话目录打开请求失效；迟到的 Session／main Thread 查询不得覆盖用户随后选择的 Thread、文件或编辑器组。沿用导航原有请求序号，不新增第二套打开调度器。

导航复用会话未读追踪 hook，按当前活动 Thread 的工作区路由和 Session 清除未读；文档隐藏或失焦时保留提示，文件编辑器不充当已读会话。活动流使用相同作用域键，避免正在阅读的会话被重新标为未读。

独立授权入口沿用 `?mcp_workspace=` 契约并直接挂载既有授权页，不启动 Workbench 布局服务；私有 OAuth 回调由构建复制 Web 唯一源文件，不能加载应用或将参数写入存储。

后端确认 Session 已消失时，先将所属 ThreadInput 排除出原版序列化并等待同一布局存储提交，再关闭全部所属编辑器；不另存删除 tombstone，不依赖文档卸载时的异步写入保证恢复正确。
