# 目录用途

`components/chat/pending/` 存放待处理消息的队列展示和投递策略控件，供 Composer 与单轮用户消息界面组合。

```text
pending/
├── PendingQueueBar.tsx          # Composer 中的待处理消息队列
└── PendingRequestActions.tsx    # 单轮待处理消息的投递策略操作
```

# 可修改内容

- 队列条目、清空/撤回控件和策略选择界面。
- 组件内仅用于反馈一次操作结果的短暂展示状态。

# 不可修改内容

- 不在本目录发起 HTTP、SSE 或其他后端请求。
- 不在本目录维护待处理消息的权威状态或持久化。
- 不解析原始 trace 协议。

# 规范

- 数据和操作回调由上层状态/交互模块提供；成功与失败由调用方按既有业务契约处理。
- 用户可见文案使用中文，专业术语除外。
- 控件提供可访问名称、禁用状态和操作反馈。
