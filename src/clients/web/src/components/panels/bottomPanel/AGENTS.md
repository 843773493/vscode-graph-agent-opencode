# 目录用途

原生工作区面板复用的 TerminalContent 与 BrowserContent。产品通过 renderToolbar 公布类型化动作，宿主接入原生标题栏与溢出菜单；标签、停靠、关闭和布局存储统一由 Workbench 负责。输出直接复用原生 OutputViewPane，由 workbench/src/workspaceOutput.ts 注册日志通道，不再维护 React 输出视图。面板范围独立选择目标与工作区，不随激活工作区变化。

# 可修改内容

- 终端列表、iframe 就绪与公开错误、浏览器资源行和预览。
- 对应内容测试直接挂载共享实现，不经过旧五标签包装。

# 不可修改内容

- 不定义协议权威或后端资源规则。
- 不恢复 BottomPanelHeader、旧面板 wrapper 或 workspaceBottomPanel 第二套状态。
- 不复制资源状态映射及 Gateway 日志展示映射。

# 规范

- 数据由实例控制器与 API 完整响应提供；保留精确 owner、revision、确认和失败重读。
- 终端测试保留 iframe 期限与授权不足；输出的工作区切换、迟到响应、隐藏及筛选恢复经原生输出入口验收。
- 标题动作随当前标签及内容来源显示。输出只有工作区后端日志显示目标／工作区选择；窗口、Launcher 和插件日志不显示。来源判断使用注册元数据，不解析显示名称、不增加查询；最大化保留在原生更多菜单。
- 终端列表只消费摘要；选中无法附加的终端时读取原资源详情展示最终输出，切换资源、工作区或版本时取消旧读取，不让列表轮询重复加载正文。
- 终端内容区不常驻标题、控制栏或状态说明；正常状态与退出码放在右侧列表及 Tooltip，传输、搜索及生命周期操作进入终端行的原生菜单，真实错误仍在所属区域显示。
- 终端连接不依赖焦点编辑器：工作区保留项无需 Thread；临时项使用原 owner 已有的来源关联签发授权，不自动关联或延长寿命。嵌入页的菜单命令只接受同源父窗口和精确终端身份，不复制资源 writer。
- BrowserContent 检查完整 Session/Thread pair、复制错误和零资源变更；真实 Gateway 生命周期独立验收。
- 导航界面错误在新宿主诊断对话框验收，不依赖输出面板再次请求服务日志。
- 修改后完成真实类型检查及 `bun run --cwd src/clients/web build`。

- 模板示例；在整理 `AGENTS.md` 时请保留此行。
