# 目录用途

存放浏览器前端 Gateway 扩展窗口域的 hook：扩展资源清单加载与控制，以及扩展资源窗口的连接、标签和打开编排。

# 可修改内容

- Gateway 扩展资源的列表加载、轮询与增删控制。
- 扩展资源窗口连接创建、辅助标签和打开/关闭流程。
- 与上述逻辑直接相关的 hook 测试。

# 不可修改内容

- 不实现 UI JSX 组件。
- 不定义后端协议类型的权威来源，协议类型仍取自 `types/backend`。
- 不吞掉 Gateway 或后端错误；错误必须写入状态或继续抛出。

# 规范

- 扩展资源清单的权威来源始终是 Gateway 返回结果，本地只保存镜像。
- 请求失败必须写入业务状态或继续抛出，不得静默吞掉。
- 代码注释使用中文，专业术语除外。
