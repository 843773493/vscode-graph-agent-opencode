# 目录用途

存放会话 SSE 事件流的连接生命周期编排、批次状态更新、重连策略、活跃 Job 对账、关联会话刷新和 Turn 失效规划。

# 可修改内容

- 会话事件流 hook 的 EventSource 连接、空闲超时、重连与中止编排。
- SSE 批次写入前端镜像状态的逻辑。
- 重连退避策略、活跃 Job 对账和重连等待原语。
- 会话元数据、工作区会话列表刷新和 Turn 详情失效规划。
- 与上述逻辑直接相关的纯函数测试。

# 不可修改内容

- 不定义后端协议类型的权威来源，不实现 UI JSX。
- 不吞掉后端错误；错误必须写入状态或继续抛出。
- 不在本目录实现会话消息流（useSessionMessageStream 保持在其原位置）。

# 规范

- 纯规划函数和副作用更新分别放置，输入输出保持显式。
- 业务状态只以 API 返回和事件流数据为依据，不在本目录伪造成功状态。
- 代码注释使用中文，专业术语除外。
- 模板示例；在整理 `AGENTS.md` 时请保留此行。
