# 目录用途

存放会话视图状态、Turn 时间线读取、会话目标控制器、会话动作聚合、会话数据装载与会话资源浏览，以及会话运行/生命周期动作、消息流订阅和后台会话活动对账这几条会话级 hook，负责把会话打开后的视图状态、Turn 快照、Goal 增删改、会话动作编排、会话变更集/资源装载、资源树浏览、消息流消费和后台 Job 对账编排成可复用的副作用单元。

本目录与同级会话子包的分工边界：

- `hooks/sessionEventStream/`：会话 SSE 事件流的连接生命周期、重连与批次更新，输入是事件流数据；本目录的消息流 hook 与后台活动 hook 复用其重连策略与等待原语，不重复实现连接。
- `hooks/sessionTurnHistory/`：Turn 历史分页与详情加载，本目录只读取其结果、不实现分页。
- `hooks/sessionTraceHistory/`：Trace 历史分页，与 Turn 历史相互独立。
- `hooks/sessionResourceExplorer/`：会话资源树同步与生成器资源的纯逻辑，本目录的 useSessionResourceExplorer 只负责编排调用它。
- `hooks/session/`：会话级视图状态（滚动位置、工具详情展开、follow latest）、当前 Turn 时间线读取、会话 Goal 控制器、会话动作聚合、会话运行与生命周期动作、消息流订阅、后台活动对账、会话变更集与资源装载、会话资源浏览器、会话信息剪贴板、子会话加载；不管理事件流连接实现，也不实现历史分页。

# 可修改内容

- 会话视图状态的读写、缓存与 host 适配。
- 当前 Turn 时间线与终态 Turn 加载入口。
- 会话 Goal 的读取、更新、清除与请求合并。
- 会话生命周期动作与运行动作的聚合编排。
- 会话消息流订阅与后台会话活动对账。
- 子会话列表加载。
- 会话变更集与资源列表的装载、刷新和失效。
- 会话资源浏览器的自动同步与资源树选择，以及会话信息剪贴板。
- 与上述逻辑直接相关的纯函数测试。

# 不可修改内容

- 不实现事件流连接、重连计时器或 Turn 历史分页。
- 不定义后端协议类型的权威来源，不实现 UI JSX 组件。
- 不吞掉后端错误；错误必须写入状态或继续抛出。
- 浏览器视图与 Thread 历史缓存通过显式 onError 交给宿主展示，不用普通状态文本推断错误；停止失败与校准失败并存时，拒绝的异常也保留两条原因。
- 不伪造会话业务状态，成功状态只来自后端返回值。

# 规范

- outbox 只给已交付可见出口的终态／本地持久化异常附加 `ReportedError` 回执，保留原错误原因；未报告的身份、HTTP 或 revision 故障继续正常抛出。

- 会话视图状态与 Goal 请求优先复用 `state/` 下的纯函数和既有会话子包结果。
- 会话资源初读和定时刷新由 `useSessionResourcePolling` 统一调度，复用同文件的资源 loader；宿主传入明确 owner 和可见性，不重复维护轮询实现。隐藏 document 时暂停静默刷新，切换 owner 时清除定时器。
- 导入其他 hook 或共享模块时使用显式相对路径，禁止任何指向旧平铺路径的转发层。
- 代码注释使用中文，专业术语除外。
- 目录对账由共享工作区 SSE 的提交通知触发，首次连接及重连先读快照，不再空闲定时查询；尚未受理或结果未知的本地操作保留同 ID 的短时查询与重试，受理后停止。目录刷新失去发布权使用共享 `CatalogReadSupersededError`；保留原事件水位并在重连后重新对账，不将其显示为业务失败。真实 HTTP、版本或混合批次故障仍须报错，不按文案判断取消。
- 跨分支读取遇到目录推进时，只有较新的权威 export 确认全部已读版本后，才在原重试上限内整批重读；精确 children 请求的非根父节点 404 还须由该完整节点集证明全部父节点已撤销。不发布混合页、不提前 prune；确认期间失去发布权不得重新抢占分支。导出落后或未推进、仍存在父节点的 404、其它 HTTP 失败或持续无法取得一致版本仍须报错。
- 修改本目录后需要运行前端静态检查和 `bun run build`。
- 模板示例；在整理 `AGENTS.md` 时请保留此行。
