# 目录用途

存放会话视图状态、Turn 时间线读取、会话目标控制器、会话动作聚合，以及会话数据装载与会话资源浏览这几条会话级 hook，负责把会话打开后的视图状态、Turn 快照、Goal 增删改、会话动作编排、会话变更集/资源装载和会话资源树浏览编排成可复用的副作用单元。

本目录与同级会话子包的分工边界：

- `hooks/sessionEventStream/`：会话 SSE 事件流的连接生命周期、重连与批次更新，输入是事件流数据。
- `hooks/sessionTurnHistory/`：Turn 历史分页与详情加载，本目录只读取其结果、不实现分页。
- `hooks/sessionTraceHistory/`：Trace 历史分页，与 Turn 历史相互独立。
- `hooks/sessionResourceExplorer/`：会话资源树同步与生成器资源的纯逻辑，本目录的 useSessionResourceExplorer 只负责编排调用它。
- `hooks/session/`：会话级视图状态（滚动位置、工具详情展开、follow latest）、当前 Turn 时间线读取、会话 Goal 控制器、会话动作聚合、会话变更集与资源装载、会话资源浏览器、会话信息剪贴板；不管理事件流连接，也不实现历史分页。

# 可修改内容

- 会话视图状态的读写、缓存与 host 适配。
- 当前 Turn 时间线与终态 Turn 加载入口。
- 会话 Goal 的读取、更新、清除与请求合并。
- 会话生命周期动作与运行动作的聚合编排。
- 会话变更集与资源列表的装载、刷新和失效。
- 会话资源浏览器的自动同步与资源树选择，以及会话信息剪贴板。
- 与上述逻辑直接相关的纯函数测试。

# 不可修改内容

- 不实现事件流连接、重连计时器或 Turn 历史分页。
- 不定义后端协议类型的权威来源，不实现 UI JSX 组件。
- 不吞掉后端错误；错误必须写入状态或继续抛出。
- 不伪造会话业务状态，成功状态只来自后端返回值。

# 规范

- 会话视图状态与 Goal 请求优先复用 `state/` 下的纯函数和既有会话子包结果。
- 导入其他 hook 或共享模块时使用显式相对路径，禁止任何指向旧平铺路径的转发层。
- 代码注释使用中文，专业术语除外。
- 修改本目录后需要运行前端静态检查和 `bun run build`。
- 模板示例；在整理 `AGENTS.md` 时请保留此行。
