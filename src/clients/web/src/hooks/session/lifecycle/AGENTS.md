# 目录用途

按用户可见的会话生命周期职责组织动作 hook：选择、创建与上下文分支、会话目录修改、Agent/模型切换和工作区默认项。`useSessionLifecycleActions` 只负责组合这些职责并维持原对外契约。

# 可修改内容

- 本目录中对应生命周期职责的 hook 与会话状态收敛逻辑。
- 生命周期 hook 的共享输入类型。
- 与上述行为直接相关的单元测试及组合测试。

# 不可修改内容

- 不在这里实现会话 API、Gateway 路由或 React 视图组件。
- 不改变后端权威状态、会话目录或 workspace route 的契约。
- 不添加旧平铺路径的转发实现。

# 规范

- 每个 hook 只编排一个清晰的会话生命周期职责；共享的状态转移与其本地持久化、事件副作用放入语义明确的函数模块。
- 对外动作由 `../useSessionLifecycleActions.ts` 组合，保持现有调用方契约。
- 新增运行时目录仍按仓库要求补充测试与静态检查。
- 模板示例；在整理 `AGENTS.md` 时请保留此行。
