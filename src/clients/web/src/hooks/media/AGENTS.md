# 目录用途

存放消息媒体源 hook：按会话与附件拉取媒体 Blob、维护媒体源列表与加载错误、提供重新加载入口，负责把消息附件的媒体加载链路拆成可复用的副作用单元。

# 可修改内容

- 会话附件媒体的拉取、缓存与错误收集。
- 媒体源列表的重载入口。
- 与上述逻辑直接相关的纯函数测试。

# 不可修改内容

- 不定义后端协议类型的权威来源，不实现 UI JSX 组件。
- 不吞掉媒体加载错误；错误必须写入状态并可供 UI 展示。
- 不伪造媒体源，成功状态只来自后端返回的 Blob。

# 规范

- 媒体类型与 URL 处理优先复用 `utils/messageMedia` 下的纯函数。
- 导入其他 hook 或共享模块时使用显式相对路径，禁止任何指向旧平铺路径的转发层。
- 代码注释使用中文，专业术语除外。
- 修改本目录后需要运行前端静态检查和 `bun run build`。
- 模板示例；在整理 `AGENTS.md` 时请保留此行。
