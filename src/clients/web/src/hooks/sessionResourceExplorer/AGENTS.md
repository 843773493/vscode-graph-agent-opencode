# 目录用途

存放会话资源浏览器按领域拆分的状态与请求 Hook，避免顶层 `hooks/` 继续堆积跨领域实现。

# 可修改内容

- 会话资源树、生成器和搜索相关的局部状态组合。
- 对现有 API 客户端的调用与后端状态镜像更新。

# 不可修改内容

- 不在此目录实现后端业务规则或伪造业务成功状态。
- 不直接读写工作区 `.boxteam/` 数据。

# 规范

- 后端返回对象是权威状态，成功后使用完整返回值更新镜像。
- 请求失败必须向调用方或错误状态暴露，不得静默伪造默认结果。
- 领域 Hook 应保持职责单一，并通过稳定返回对象供组合 Hook 使用。
- `resourceTreeSync` 统一定义目录读取失效类型，供读取方与 outbox 对账方传递发布权取消；类型不能替代真实 HTTP／版本错误，不推进已消费事件水位。
