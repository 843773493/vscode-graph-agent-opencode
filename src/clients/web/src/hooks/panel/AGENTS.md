# 目录用途

存放主窗口与扩展窗口的面板布局 hook：底部面板与主区域拖拽 resize、工作台面板可见性路由，负责把面板几何与可见性变更落到工作区布局设置。

# 可修改内容

- 底部面板、主区域和扩展调试区域的拖拽 resize 与尺寸落盘。
- 辅助面板、聊天面板和底部面板的路由与可见性切换。
- 与上述逻辑直接相关的纯函数测试。

# 不可修改内容

- 不定义后端协议类型的权威来源，不实现 UI JSX 组件。
- 不吞掉布局持久化错误；错误必须写入状态或继续抛出。
- 不管理会话内容渲染，不读写会话业务数据。

# 规范

- 面板几何计算优先复用 `layout/workbenchLayout` 下的纯函数。
- 导入其他 hook 或共享模块时使用显式相对路径，禁止任何指向旧平铺路径的转发层。
- 代码注释使用中文，专业术语除外。
- 修改本目录后需要运行前端静态检查和 `bun run build`。
- 模板示例；在整理 `AGENTS.md` 时请保留此行。
