# 目录用途

存放浏览器视图设置控制器：按稳定 Gateway 身份读写 IndexedDB、同步本地展示状态；旧账户原件不自动导入或删除，负责把设置同步链路拆成可复用的副作用单元。

# 可修改内容

- 浏览器展示设置的读取、事务更新与同源窗口同步。
- 背景参数只读解析；本机凭据认证不增加访问心跳，访问状态不决定视图能否保存。配色选择只由 Workbench profile 维护。
- 与上述逻辑直接相关的纯函数测试。

# 不可修改内容

- 不定义后端协议类型的权威来源，不实现 UI JSX 组件。
- 不吞掉设置或主题加载错误；错误必须写入状态或继续抛出。
- 同源变更的异步读取失败通过必传 onError 交给宿主；保存操作继续拒绝 Promise 并保留失败重读，不依赖旧工作台状态栏。
- 不伪造设置状态，业务成功状态来自后端，视图保存成功必须以 IndexedDB 事务提交为准。

# 规范

- 设置归一与合并优先复用 `state/uiSettings/` 下的纯函数。
- 导入其他 hook 或共享模块时使用显式相对路径，禁止任何指向旧平铺路径的转发层。
- 代码注释使用中文，专业术语除外。
- 修改本目录后需要运行前端静态检查和 `bun run build`。
- 模板示例；在整理 `AGENTS.md` 时请保留此行。
