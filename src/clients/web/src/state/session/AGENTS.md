# 目录用途

存放浏览器前端与会话相关的纯状态派生、树结构、作用域键和通用会话信息协议转换。

# 可修改内容

- 会话列表与树结构的纯函数。
- 会话作用域键、通用会话信息格式化与解析。
- 不发起网络请求的数据转换和校验逻辑。

# 不可修改内容

- 不实现 React 组件、浏览器副作用或后端业务规则。
- 不直接调用后端 API 或写入权威会话状态。

# 规范

- 目录 outbox 升级以实际命令为准：只剩计数器时自动保留原键值，并在既有迁移元数据中冻结最大序号下限，不要求身份映射；仍有旧命令时必须核对归属，不猜测或重放。序号分配只读当前计数器和该冻结下限，不在普通操作中扫描历史。
- 函数保持纯净，输入输出显式，非法输入必须抛出明确错误。
- Turn 时间线的正文保留范围由虚拟列表实际挂载窗口决定；窗口之外的终态回合只留明确标记的定位记录，不能让原始 summary 再持有已释放正文。活动回合及最近两轮保留，补读继续使用原历史 reader 和后端游标。
- 会话信息协议变更必须同步公开类型、解析测试和后端 DTO。
- 会话树按`parent_session_id`连接，缺失父节点的会话提升为根，循环关系明确报错；根和子节点均按选定时间倒序。时间戳只在排序比较首次需要时按节点缓存，不进入返回树，单节点分组不解析时间。
- 代码注释使用中文，专业术语除外。
- 保留“模板示例；在整理 `AGENTS.md` 时请保留此行。”这一行。
