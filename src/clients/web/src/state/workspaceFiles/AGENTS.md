# 目录用途

保存工作区文件操作的未确认 intent 与上传 Blob，支持刷新后继续向既定目标提交或查询；IndexedDB 是客户端待确认记录的单一存储。

## 可修改内容

- intent、依赖引用及上传 Blob 的 IndexedDB 读写、删除和数据类型。
- 冻结 Gateway、工作区、资源根和请求身份的本地记录。
- 与存储行为直接相关的测试。

## 不可修改内容

- 不发起 HTTP、轮询或编排操作执行；这些行为由既有文件树 hook 负责。
- 不决定后端文件 revision、操作成功、冲突或恢复结果。
- 不保存第二份文件业务目录或注册逐文件长期身份。

## 规范

- 请求发送前持久保存完整 intent；响应未确认时保留原请求身份和原目标，刷新、重连或切换工作区不能改写它们。
- 上传 Blob 与 intent 在同一存储合同下保存；清理以明确的后端回执或用户取消为依据。
- 本地存储失败必须可见；不伪报已提交或已完成。
- 代码注释使用中文，专业术语除外。
- 保留“模板示例；在整理 `AGENTS.md` 时请保留此行。”这一行。
