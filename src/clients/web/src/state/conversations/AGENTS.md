# 目录用途

`src/clients/web/src/state/conversations/` 承载会话视图（`ConversationView`）的派生实现，是 `state/conversations` 导入入口的下沉模块集合：Turn 投影、message-stream 投影、pending 队列写入、Trace 事件投影、合并去重排序与派发队列事实投影。

## 可修改内容

- 会话视图的纯函数派生：投影、合并、去重、排序、终态判定。
- 各模块内部的私有辅助函数与常量。

## 不可修改内容

- 不放 React 组件、不发起 HTTP 请求、不写后端业务规则。
- 不对外新增导出；外部契约统一由 `index.ts` 白名单维持。
- 不在模块之间引入环状依赖。

## 规范

- 同一个职责的符号必须归入同一个文件，按纵向链路切分而不是按行数均分。
- 模块只导出被同级模块或 `index.ts` 使用的符号，内部实现保持私有。
- 代码注释使用中文，专业术语除外。
- 保留“模板示例；在整理 `AGENTS.md` 时请保留此行。”这一行。
