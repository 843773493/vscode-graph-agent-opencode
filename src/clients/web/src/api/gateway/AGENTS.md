# 目录用途

`src/clients/web/src/api/gateway/` 存放浏览器前端的 Gateway 控制面 API 客户端：Gateway 用户访问控制与会话初始化、用户视图状态、端口转发、会话连接等 `/api/gateway/*` 契约。

与相邻模块的边界：

- `api/http.ts`（上级目录）：统一请求屏障（Gateway 凭据、用户会话初始化、重试、超时）与 JSON 解包。本包所有模块都基于它发起请求，不自带传输层。
- `api/session/`（上级目录）：工作区后端会话域 API（`/api/v1/*`），不含 Gateway 控制面契约。
- `api/stream/`（上级目录）：SSE 实时流与快照校验，与本包的一次性请求-响应语义不同。
- `types/`：后端协议类型的权威来源，本包只消费不定义。

# 可修改内容

- Gateway 控制面各 API 客户端的请求构造、响应解包与专用错误类型。
- 本包内部的模块拆分与符号导出调整。

# 不可修改内容

- 不维护 React 展示状态或会话业务状态；本包只做请求与响应转换。
- 不把共享 HTTP 传输逻辑复制进本包；传输能力只来自 `api/http.ts`。
- 不定义后端协议类型的权威来源；协议类型只能来自 `src/clients/web/src/types/`。

# 规范

- 按语义模块组织文件，每个文件只承载一族 Gateway 控制面契约。
- 请求失败必须透明抛出，不得静默降级；调用方以 `HttpRequestError` 区分的语义保持不变。
- 导入上级共享模块使用显式相对路径（如 `../http`、`../../types/backend`），禁止任何指向旧平铺路径的转发层。
- 跨模块共享的模块级可变状态必须只存在一份实例，禁止在多处复制同一缓存。
- 代码注释使用中文，专业术语除外。
