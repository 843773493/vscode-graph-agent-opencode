# 目录用途

存放 `src/clients/web/src/api/` 各 API 客户端的聚焦测试：根级 `api`、`gatewayApi` 以及工作区文件事件流客户端的请求编排与响应解包行为。

# 可修改内容

- 可以新增和维护只依赖 `src/clients/web/src/api/` 与其相邻模块的测试文件。
- 可以添加小型响应/事件构造 helper，但应保持用例聚焦。

# 不可修改内容

- 不在这里放 React 组件测试或产品运行时代码。
- 不在这里伪造成功状态；失败必须按真实错误路径断言。

# 规范

- 单个测试文件只覆盖一个主要 API 客户端或一条明确的请求链路。
- 测试必须替换并恢复 `globalThis.fetch`，不得发出真实网络请求。
- 保留“模板示例；在整理 `AGENTS.md` 时请保留此行。”这一行。
