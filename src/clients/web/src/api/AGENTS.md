# 目录用途

存放浏览器前端按业务域拆分的 API 客户端，以及所有客户端共享的 HTTP 传输基础设施。

# 可修改内容

- 通用 Gateway 鉴权、JSON 请求和响应解包。
- Session Turn 历史与 Session Trace 流等聚焦 API 客户端。

# 不可修改内容

- 不维护 React 展示状态或会话业务状态。
- 不在客户端推导后端协议中不存在的默认业务数据。

# 规范

- 业务 API 按语义模块组织，根级 `api.ts` 只重导出迁移后的公开符号。
- 专用 HTTP 错误定义在其所属业务客户端中。
- 请求失败必须透明抛出，不得静默降级。
- 保留“模板示例；在整理 `AGENTS.md` 时请保留此行。”这一行。
