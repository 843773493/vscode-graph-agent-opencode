# 目录用途

存放浏览器前端的运行时主题子包：`theme` 负责把 Gateway 解析后的主题配置（配色模式、`--bt-*` token、背景图片）应用到文档根节点，并在加载背景图失败时抛出显式错误。

本目录与相邻模块的分工边界：

- `styles/theme.css`、`styles/themeSurfaces.css`：主题相关的静态样式表，本包只负责运行时应用，不定义样式规则。
- `state/uiSettings/`：界面偏好的业务状态与持久化，本包只消费已解析的主题配置，不拥有状态权威。
- `api/`、`api/session/`：Gateway 主题接口的请求编排，本包只接收其结果。
- `types/backend.ts`、`types/gatewayProtocol.ts`：后端协议类型的权威来源，本包的类型只描述运行时配置形态。

# 可修改内容

- 主题 token、配色模式与背景图的应用逻辑。
- 运行时主题事件监听的安装与卸载边界。
- 与上述逻辑直接相关的纯函数测试。

# 不可修改内容

- 不在本目录维护 React 展示状态或后端业务状态权威。
- 不吞掉主题变量校验、背景图加载或事件载荷错误；错误必须继续抛出。
- 不在此定义后端协议类型的权威来源。

# 规范

- 主题变量必须使用 `--bt-` 命名空间，应用前显式校验，失败即抛出。
- 导入共享模块使用显式相对路径，禁止任何指向旧平铺路径的转发层。
- 代码注释使用中文，专业术语除外。
- 修改本目录后需要运行 `bun run --cwd src/clients/web build`。
- 模板示例；在整理 `AGENTS.md` 时请保留此行。
