# 目录用途

存放浏览器前端的运行时主题子包：`theme` 只消费当前 Workbench settings.json 的背景图片及位置、尺寸、重复和遮罩参数。配色与明暗模式由原 Workbench 主题服务负责，不允许将 Gateway 颜色 token 写入宿主。背景图失败返回明确警告并清除图片。

本目录与相邻模块的分工边界：

- `styles/foundation/theme.css`、`styles/foundation/themeSurfaces.css`：主题相关静态样式表；本包只负责运行时应用，不定义样式规则。
- `state/uiSettings/`：界面偏好的业务状态与持久化，不保存主题或背景配置。背景的唯一权威来源是原 Workbench 配置服务。
- `api/`、`api/session/`：Gateway 图片资源接口的请求编排，不提供配色或背景设置解析。
- `types/backend.ts`、`types/gatewayProtocol.ts`：后端协议类型的权威来源；本包只定义原生 Workbench 展示设置，不作为后端 DTO。

# 可修改内容

- 背景图片及其布局参数的应用逻辑。
- 图片预载的取消发布与宿主释放边界。
- 与上述逻辑直接相关的纯函数测试。

# 不可修改内容

- 不在本目录维护 React 展示状态或后端业务状态权威。
- 不维护第二套主题选择或配色运行时；背景图失败须返回原始原因，由调用宿主可见地展示警告。
- 不在此定义后端协议类型的权威来源。

# 规范

- 只写明确列出的 `--bt-background-*` 参数，不按传入 token 批量写入样式。
- 传入取消信号时，在图片预载前及应用成功／失败主题前检查发布权；不允许过期回执改写其它主题，不宣称取消了图片网络请求。
- 导入共享模块使用显式相对路径，禁止任何指向旧平铺路径的转发层。
- 代码注释使用中文，专业术语除外。
- 修改本目录后需要运行 `bun run --cwd src/clients/web build`。
- 模板示例；在整理 `AGENTS.md` 时请保留此行。
