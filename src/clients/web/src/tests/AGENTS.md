# 目录用途

`src/clients/web/src/tests/` 存放跨越多个 Web 源码子目录的契约守卫测试，例如校验跨客户端共享选择器与真实 DOM 属性保持一致。

# 可修改内容

- 可以新增和维护需要同时读取多个 `src/clients/web/src/` 子目录或仓库级测试资产的一致性测试。
- 可以添加小型文本解析 helper，但应保持用例聚焦。

# 不可修改内容

- 不在这里放单个组件或单个纯函数的局部行为测试，那些测试应与被测源码同目录。
- 不在这里放产品运行时代码。

# 规范

- 一个测试文件只守一条跨目录契约，断言要能指出漂移发生在哪个文件。
- 读取源码或测试资产时使用 `import.meta.url` 相对定位，保持不变更当前工作目录也能运行。
- 保留“模板示例；在整理 `AGENTS.md` 时请保留此行。”这一行。
