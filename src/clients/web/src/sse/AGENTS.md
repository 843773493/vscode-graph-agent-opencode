# 目录用途

存放浏览器前端的 SSE 客户端协议层：`sseClient` 从共享实现重导出帧解析、事件定义与消费原语，`sseRuntimeSchemas` 在运行时校验 SSE 载荷（Trace 事件、会话执行事件、工作区文件批次）后再交给业务层。

本目录与相邻模块的分工边界：

- `api/stream/`、`api/session/`：具体接口的请求编排与端点定义，只**消费**本目录原语，不在此定义协议解析。
- `protocol/`：后端协议的权威类型与解析器，本目录的 sseRuntimeSchemas 只做组合校验，不重复定义类型。
- `runtime/`：按需加载的重量级第三方运行时；本目录是轻量协议层，不得并入 runtime/。
- `../../../shared/sse.js`：跨客户端共享的 SSE 原语实现，本目录只重导出，不复制实现。

# 可修改内容

- SSE 帧解析与事件定义的重导出边界。
- SSE 载荷的运行时校验组合（Trace、会话执行、工作区文件批次）。
- 与上述逻辑直接相关的纯函数测试。

# 不可修改内容

- 不在本目录重复实现 `shared/sse.js` 的协议原语。
- 不定义后端协议类型的权威来源（归 `protocol/`）。
- 不吞掉解析或校验错误；错误必须继续抛出。

# 规范

- 校验函数保持输入输出显式，失败即抛出，不返回虚假默认值。
- 导入共享模块使用显式相对路径，禁止任何指向旧平铺路径的转发层。
- 代码注释使用中文，专业术语除外。
- 修改本目录后需要运行 `bun run --cwd src/clients/web build`。
- 模板示例；在整理 `AGENTS.md` 时请保留此行。
