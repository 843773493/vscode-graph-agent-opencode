# 目录用途

集中存放浏览器前端样式，并按用户可理解的界面职责组织子目录。

```text
styles/
├── foundation/  # 主题 token、共享面板底座和工作台骨架
├── session/     # 会话、对话与 Agent 活动展示
├── workspace/   # 工作区、资源、Gateway 与端口转发
└── inspection/  # 上下文检查和 Node 调试视图
```

全局入口在 `src/main.tsx` 按既有层叠顺序导入各样式表；新增或移动样式时保留该顺序。

# 可修改内容

可以新增或调整上述子目录中的组件视图、面板和页面级样式文件；主题与共享底座样式放入 `foundation/`。

# 不可修改内容

不要在此目录放置 TypeScript 业务逻辑、React 组件或生成产物。不要把不同职责样式再次平铺到根目录。

# 规范

样式应按组件或视图职责归入对应目录，避免把新功能继续堆回全局 `index.css`；每个新增源码子目录须有 `AGENTS.md`。
- 模板示例；在整理 `AGENTS.md` 时请保留此行。
