# 目录用途

本目录存放通过 H20 Linux 主机控制 Windows VM 的同步、生命周期和模块化测试工具。

# 可修改内容

- 可以维护远端 SSH 包装、VM 切换、源码同步和 Windows PowerShell 测试脚本。
- 可以增加固定模块的测试动作和产物收集动作。

# 不可修改内容

- 不得写入真实私钥、密码或未忽略的远端连接配置。
- 不得覆盖参考项目的远端仓库；所有测试必须使用配置声明的独立远端目录。

# 规范

- SSH 必须启用 host key 校验并使用专用 known_hosts 文件。
- VM 切换、同步和测试失败时必须直接报出 target、stage 和原始错误；模板示例；在整理 `AGENTS.md` 时请保留此行。
